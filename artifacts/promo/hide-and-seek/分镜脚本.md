# 分镜脚本：躲猫猫

竖屏，1080 × 1920，60 fps，35 秒，没有声音。文案是简体中文，截图用官网简体中文、暗色的一套。

## 设计思路

“躲猫猫” 系列的四组图标，是同一场躲猫猫的四个瞬间：幽灵是 Spooky，紫色的服务器是放着仓库的那台机器。

宣传片把这四个瞬间按故事的先后接成四幕，每一幕都在对应图标的构图上定格一次：

| 幕 | 图标 | 这一幕说什么 |
|---|---|---|
| 一 | 藏身：幽灵从机柜背后探出来，一只小手扒着机柜的边 | 仓库在服务器上，Spooky 找得到 |
| 二 | 探身：幽灵从两层的机架后升起来，举起两只小手 | 它是谁：名字与一句话的介绍 |
| 三 | 身前：幽灵浮在三层的机架前面，小手抬向指示灯 | 怎样连上：一个主机别名，一个路径 |
| 四 | 显形：服务器往上投出一束光，幽灵浮在光里 | 连上之后能做什么：完整的 Git 工作流 |

App 里这四组的顺序是探身、身前、藏身、显形；片子里按 “藏起来 → 被找到 → 走到身前 → 显出全貌” 重排。

贯穿全片的几条规矩：

- **一直在躲猫猫**
  - 幽灵每次离场都是躲起来：缩回机柜背后、沉回机架后面、沉出画面、缩到截图后面
  - 下一次从别的地方冒出来，第四幕里每换一张截图就换一个地方探头
- **画面就是图标**
  - 幽灵、服务器、光束与星星都由应用图标的绘制脚本画出，炭黑的底板、奶油白的贴纸边、紫色的服务器都与图标相同
  - 截图卡片镶着同一圈贴纸边，和幽灵是同一套贴纸
- **指示灯**
  - 图标里，App 连着服务器时指示灯亮起一绿一青
  - 片子里，指示灯灭着是还没连上，亮起的那一下是连上了：第三幕在幽灵抬手一点的时候，第四幕与光束同时
  - 三条说明前面的圆点也用这两种颜色
- **文字不动**
  - 文字与截图出现之后位置、大小都不再改变，只有淡入与淡出
  - 会动的只有画

## 封面

发到社交媒体上时，视频的封面通常取第一帧，所以全片的第一帧就按封面来画：幽灵从机柜背后探出半个身子、望着镜头，上方是问句。

- 开场的 0.75 秒里画面几乎不动：平台取第一帧还是稍后的一帧，拿到的都是这幅画面
- 之后幽灵眨一下眼，整个缩回机柜背后，过一会儿再探出来，这一次大半个身子都在外面：被看见、躲起来、又被找到，正好是一次躲猫猫
- 可以另外上传封面的平台用 `out/cover.png`：同一帧，问句下面多一行 “Spooky · 原生的 macOS Git 客户端”，成片里没有这一行

# Spooky 宣传片：cherry-pick

竖屏宣传片。应用图标 “cherry-pick” 系列的四组图标画的是幽灵摘樱桃，全片照它排成四幕：午夜、栖枝、采撷、满怀。

- 成片：`out/cherry-pick.mp4`，不存进仓库，按 “重新渲染” 一节生成
  - 1080 × 1920，60 fps，20.75 秒
  - H.264（High，yuv420p，BT.709），约 17 MB，没有声音
- 封面图：[`out/cover.png`](out/cover.png)
  - 视频的封面通常取第一帧，成片的第一帧就是按封面画的
  - 可以另外上传封面的平台用这一张：同一帧，大标语下面多一行名字与介绍，成片里没有这一行
- 分镜与文案：[`分镜脚本.md`](分镜脚本.md)
- 各幕的静帧：`out/stills/`，文件名是所在的时刻（秒）

## 画面的来源

- 满月、幽灵、枝、叶、樱桃、星星与片尾的应用图标
  - 由仓库的 `scripts/make-icon/` 画出，与应用图标是同一套绘制脚本
  - 画面的坐标就是图标的坐标：图标的 1024 网格贴着成片的底边铺满整宽，四组图标的构图原样搬进成片
  - 栖枝一幕是远景：整幅画缩到 54%，图标落在画面的右下角，上方留给截图
  - 照故事改了两处，与图标不同：樱桃梗顶上的叶子，与远景里满月的位置，见分镜脚本的 “画面就是图标”
  - 绘制脚本改了，重新渲染后成片跟着变
- 截图
  - 官网简体中文、暗色的一套：`website/src/assets/screenshots/zh-cn/dark/`
  - 按截图的像素一比一取景，不缩放

## 文字不动

成片里的文字不能有任何晃动，画面按下面的规则搭：

- 文字、截图卡片与片尾的应用图标都是位置固定的元素
  - 位置与大小取整数像素，不加任何变换
  - 出现与消失只改不透明度
- 会动的只有画：满月、幽灵、枝、樱桃与星星
  - 镜头拉远、推近时缩放的也只有画，截图卡片的贴纸边与投影不跟着缩
- 文字一律按灰度抗锯齿，同一行字在任何不透明度下栅格出来的形状都相同
- 页面里没有定时器，也没有 CSS 动画与过渡；每一帧只由时间决定，重复渲染得到同样的画面
- 编码时关键帧只放在画面上没有文字停留的时刻，即 `src/plan.js` 的 `KEYFRAMES`
  - 关键帧落在文字停留的时候，编码器把整帧重画一遍，文字的边缘会跟着跳一下
  - 全片的第一帧除外：它必然是关键帧，开场的大标语从这一帧起就在
- 编码不用 B 帧
  - B 帧里静止的细线会按邻近的运动去预测，亮度略有偏差，看上去隔一帧闪一下
- 编码用恒定的量化参数（`-qp 12`），不用 CRF
  - 量化参数全片不变，静止的文字编码一次就到位，此后的帧原样沿用
  - CRF 会随时间调整每个宏块的量化参数，静止的文字被一次次细微地修正
- 色度量化到 4：默认的量化参数下比亮度细 8 级（`-chromaoffset -8`）
  - 色度量化得粗时，静止的画面里均值正好落在两级之间的色度小块，编码器每一帧都往另一边修正一级，颜色隔一帧闪一下
  - 量化到这么细，静止的画面几帧之内编到位，此后的帧原样沿用
- 编码不用去块滤波
  - 静止的区域里某个宏块的编码方式一变，去块滤波的强度跟着变，宏块边上的一列像素会跳一下
  - 量化参数取得低，画面上没有要它掩盖的方块

改动画面时守住这几条：要让文字 “动起来” 的效果一律不做。

## 重新渲染

需要 Node 22.12 或更高版本，以及本机的 Chrome 或 Chromium。字体与官网截图存在 Git LFS 里，克隆前先装好它才能取到。

```sh
cd artifacts/promo/cherry-pick
npm ci
node render.mjs
```

常用的几种：

```sh
# 全片，输出到 out/cherry-pick.mp4
node render.mjs

# 只渲染一段，输出到 out/cherry-pick-3.6-11.5.mp4
node render.mjs --from 3.6 --to 11.5

# 导出几个时刻的静帧到 out/stills/
node render.mjs --stills 1.1,9.4,16

# 导出封面图到 out/cover.png
node render.mjs --cover
```

- 浏览器不在默认位置时，用环境变量 `CHROME` 指定可执行文件
- `--qp` 改量化参数，默认 12，越小越清晰、文件越大
- `--fps` 改帧率，预览时用
- 全片 1245 帧，逐帧截图再编码，约需十二分钟

## 改文案与节奏

都在 `src/plan.js`：

- `LENGTHS` 是四幕各自的时长，其余时刻都相对各幕的起止给出
- `TEXTS` 是全片的文字：内容、位置、出现与消失的时刻
- `CARDS` 与 `BEAT_SHOTS` 是截图卡片：用哪张截图、取景与位置
- `COVER` 是封面图：取成片的哪一帧，以及只在封面图上的那一行

<More>[Cómo funcionan los repositorios de servidor](/guide/server/overview/)</More>

<Grid columns={4}>

<Point icon="server" title="Sin clon en tu Mac">

El árbol de trabajo se queda en el servidor. No hace falta clonarlo antes en tu Mac.

</Point>

<Point icon="terminal" title="Git se ejecuta en el servidor">

Spooky usa el Git del propio servidor, y lee y escribe los archivos por SSH.

</Point>

<Point icon="key" title="El SSH que ya usas">

Las conexiones usan el SSH del sistema y los alias de host de `~/.ssh/config`. OpenSSH se encarga de la autenticación, las claves de host y la conexión compartida.

</Point>

<Point icon="script" title="Sin root ni servicios en segundo plano">

Spooky no necesita acceso de root en el servidor ni instala ningún servicio en segundo plano. Solo guarda un pequeño script de ayuda en `~/.spooky/bin/`.

</Point>

</Grid>

<Feature
  title="Un alias de host y una ruta"
  shots={[
    {

      frame: 'dialog',

>

Selecciona :ui[action.addRemote], introduce un alias de host de `~/.ssh/config` y escribe la ruta del repositorio en el servidor o búscala en él.

Spooky comprueba la conexión y abre el repositorio.

</Feature>

</Section>

<Section

<Feature
  title="Ramas, sincronización, fusión y rebase"
  reverse
  shots={[
    { name: 'branches', alt: 'La sección Ramas de la barra lateral.', frame: 'closeup' },
    { name: 'sync', alt: 'El diálogo de push, haciendo push de main a origin/main.', frame: 'dialog' },
  ]}
>

Haz fetch, pull y push desde la barra de herramientas.

Arrastra una rama sobre la actual para fusionarla, o mantén pulsada <kbd>⌥</kbd> mientras arrastras para hacer rebase sobre ella.

</Feature>

<Feature
  title="Un asistente para los conflictos"
  reveal
  shots={[
    {
      name: 'conflict',
      alt: 'El asistente de conflictos tras una fusión, con las dos versiones de src/units.ts.',
      frame: 'window',
    },
  ]}
>

Para cada archivo en conflicto, Spooky muestra la versión de cada lado.

Elige una para resolver el archivo con ella, o selecciona las dos y abre una herramienta de fusión.

</Feature>

<Grid columns={4}>

<Point icon="history" title="Historial y búsqueda">

Sigue cada rama en el gráfico de commits. Busca por mensaje, autor, committer, archivo, hash del commit o fecha.

</Point>

<Point icon="undo" title="Deshacer y rehacer">

Los commits, los reverts, los stashes y otras operaciones se deshacen con <kbd>⌘Z</kbd> y se rehacen con <kbd>⇧⌘Z</kbd>.

</Point>

<Point icon="pullRequest" title="Pull requests y merge requests">

Puedes listarlas, crearlas, comentarlas, hacer checkout de ellas, fusionarlas y cerrarlas en GitHub, GitLab.com y <mark>GitLab autogestionado</mark>.

</Point>

<Point icon="layers" title="Stashes, submódulos, <mark>worktrees</mark> y Git LFS">

Todos funcionan también en los repositorios de servidor.

</Point>

</Grid>

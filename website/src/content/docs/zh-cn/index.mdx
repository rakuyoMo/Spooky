<Grid columns={4}>

<Point icon="server" title="不用克隆到本机">

工作区留在服务器上，不用先克隆到本机。

</Point>

<Point icon="terminal" title="Git 在服务器上执行">

Spooky 用服务器上的 Git，文件经 SSH 读写。

</Point>

<Point icon="key" title="用你现有的 SSH">

连接用系统自带的 SSH 和 `~/.ssh/config` 里的主机别名，认证、主机指纹与连接复用都交给 OpenSSH。

</Point>

<Point icon="script" title="不要 root，不装常驻服务">

服务器上不需要 root，也不装常驻服务；Spooky 只在 `~/.spooky/bin/` 放一个小脚本。

</Point>

</Grid>

<Feature
  title="一个主机别名，一个路径"
  shots={[
    {
      name: 'add-server',
      alt: '添加服务器仓库的对话框，填好了主机别名 spooky-test 与路径 /srv/git/driftwood。',
      frame: 'dialog',
    },
  ]}
>

选 :ui[action.addRemote]，填上 `~/.ssh/config` 里的主机别名，再输入或浏览到服务器上仓库的路径。

Spooky 检查连接之后打开仓库。

</Feature>

</Section>

<Section
  id="workflow"
  kicker="完整的 Git 工作流"
  title="从第一处改动，到合并分支"

>

<Feature
  title="分支、同步、合并与变基"
  reverse
  shots={[
    { name: 'branches', alt: '侧边栏的分支一节。', frame: 'closeup' },
    { name: 'sync', alt: '推送对话框：把 main 推到 origin/main。', frame: 'dialog' },
  ]}
>

在工具栏上获取、拉取、推送。

把分支拖到当前分支上就是合并，拖的时候按住 <kbd>⌥</kbd> 就是变基。

</Feature>

<Feature
  title="冲突向导"
  reveal
  shots={[
    {
      name: 'conflict',
      alt: '合并之后的冲突向导，摆出 src/units.ts 两边的版本。',
      frame: 'window',
    },
  ]}
>

每个冲突的文件，Spooky 都把两边的版本摆出来。

选一个，就用它解决；两个都选，就交给合并工具。

</Feature>

<Grid columns={4}>

<Point icon="history" title="历史与搜索">

在提交图里看每条分支的走向，按提交信息、作者、提交者、文件、提交哈希或日期搜索。

</Point>

<Point icon="undo" title="撤销与重做">

提交、反转、储藏等操作，按 <kbd>⌘Z</kbd> 撤销，按 <kbd>⇧⌘Z</kbd> 重做。

</Point>

<Point icon="pullRequest" title="Pull Request 与 Merge Request">

在 GitHub、GitLab.com 与<mark>私有部署的 GitLab</mark> 上列出、创建、讨论、检出、合并和关闭。

</Point>

<Point icon="layers" title="Stash、Submodule、<mark>Worktree</mark> 与 Git LFS">

服务器仓库里也都能用。

</Point>

</Grid>

</Section>

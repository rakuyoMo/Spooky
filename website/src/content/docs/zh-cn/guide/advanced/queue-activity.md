Spooky 改动一个仓库时，一次只做一个操作。别的操作正在执行时你又发起了一个，它会排队等着，而不是被拒绝。读取状态、历史和 Diff 不用等。

## 操作怎样排队 {#queue}

仓库里没有操作在执行时，新的操作马上开始。否则它排进这个仓库的队列，按你发起的先后依次执行。显示这个仓库的所有窗口共用同一个队列。

凡是改动仓库的操作都是这样，不论从哪里发起：菜单、工具栏、右键菜单、快捷操作、拖放、连按、对话框、文件列表和提交区。

- 仓库正忙时，菜单项和按钮照样可以用。点对话框的按钮后，对话框照常关闭。
- 需要你确认的操作，比如删除分支或强推，在你点的时候就确认，轮到时不再问。
- 取决于当时仓库状态的询问，比如挡路的改动要不要储藏，在轮到时出现。

改动工作区或索引的操作执行期间，文件列表会变灰，即使操作是在另一个窗口里发起的。获取、推送等别的操作不影响文件列表，在那里做的操作排进队列。

排队等着的提交，它的提交信息和选项在开始执行前都不能改。

## 轮到时 {#turn}

前一个操作结束、窗口刷新完之后，Spooky 按仓库现在的状态核对下一个操作，用的是决定菜单项能不能点的同一套规则。操作已经不合适了，比如它要处理的分支已经没有了，就不会执行，它的记录写着 :ui[activity.skipped] 和原因。

一个操作失败时，排在它后面的都会取消，不在失败的结果上接着做。它们的记录写明是哪个操作失败了。你自己停掉正在执行的操作时，只停这一个，后面的照常进行。

以下情况也会取消排着的操作：

- 和服务器仓库的连接断开。重新连上后也不会再执行。
- 你关闭窗口，或者在这个窗口里打开别的仓库。只取消从这个窗口发起的操作。
- 你退出 Spooky。

## 撤销与重做 {#undo}

撤销和重做不排队。你发起的操作正在执行或等着时，它们不可用，菜单里写着 :ui[undo.reason.busy]。见 [暂时撤销不了](/guide/work/undo/#blocked)。

## 自动获取 {#auto-fetch}

[自动获取](/guide/branches/sync/#auto-fetch) 只在仓库里没有操作执行或等待时开始。它获取期间你发起任何操作，包括撤销和重做，它都会马上停下，让你的操作执行。它的记录写着 :ui[activity.cancelled]，以及给哪个操作让了路。

## 活动区 {#activity-area}

侧边栏底部列出窗口里这个仓库的：

- 获取、拉取、推送等要连接远端的操作，执行期间和结束后的几秒钟里都在，最新的在上面。
- 下面是在队列里等着的操作，先轮到的在上面。轮到之前，Git 输出的位置写着 :ui[activity.waitingDetail]。

每一行有进度条、停止按钮和 Git 输出的最后一行。最多同时露出三行，更多的滚动查看。

- 点等待中那一行的停止按钮，会把它移出队列。什么都不执行，这一行写明操作已取消。
- 点执行中那一行的停止按钮，会停掉这个操作。
- 点一行里的其它地方，会打开 :ui[activity.title] 窗口。

不连接远端的操作开始执行后就离开活动区，进度显示在窗口里，比如工作区或提交区。

## 活动窗口 {#activity-window}

选 :ui[menu.window > activity.title]（<kbd>⌃⌘0</kbd>）。窗口里有所有仓库的记录，分三页，在工具栏里切换：

| 页 | 列出什么 | 记录留多久 |
|---|---|---|
| :ui[activity.remote] | 获取、拉取、推送等要连接远端的操作 | 7 天，存在你的 Mac 上 |
| :ui[activity.repository] | 别的 Git 操作，以及你发起的读取，比如读取提交 | 最近的 100 条，直到退出 |
| :ui[activity.service] | 对 GitHub 和 GitLab 的请求 | 直到退出 |

::screenshot[活动窗口的远端页。列表里是一个仓库的获取、拉取与推送记录，选中的是推送，右边是它的完整日志。]{name="advanced-activity" frame="window" markers="55.2,10 37.7,4.6 93.8,4.6"}

1. 三个页面：:ui[activity.remote]、:ui[activity.repository] 与 :ui[activity.service]
2. :ui[activity.clear]
3. 搜索框

Spooky 为了让窗口保持最新而自己做的读取不会列出。

选中一条记录，右边会显示它的完整日志，文字可以选择和复制。

- 等待中的操作在这里也会列出，写着 :ui[activity.waiting]，带停止按钮。
- :ui[activity.clear] 会清掉当前页已经结束的记录，进行中的留着。
- 搜索框按仓库名和日志内容筛选当前页。

日志里不会出现密码和令牌。

## 系统通知 {#notifications}

以下情况 Spooky 会发出通知：

- 克隆完成。通知写着远端地址（去掉了其中的用户名和密码）和克隆到的位置。见 [克隆仓库](/guide/repositories/manager/#clone)。
- 自动归档了分支。通知写着归档了几个。见 [自动归档](/guide/branches/review/#auto-archive)。

Spooky 不会问你要不要允许通知，所以一开始 macOS 会把通知悄悄放进 **通知中心**。想改变通知的显示方式，选 **苹果菜单 › 系统设置**，点边栏中的 **通知**，再点 **Spooky**。点通知会把 Spooky 带到前面。

:::note[服务器仓库]
每个服务器仓库和本机仓库一样，有自己的队列。停掉操作，或者自动获取让路时，服务器上的 Git 进程也会结束。
:::

Spooky 變更一個儲存庫時，一次只做一個操作。別的操作正在執行時你又發起了一個，它會排隊等著，而不是被拒絕。讀取狀態、歷史和 Diff 不用等。

## 操作怎樣排隊 {#queue}

儲存庫裡沒有操作在執行時，新的操作馬上開始。否則它排進這個儲存庫的佇列，按你發起的先後依序執行。顯示這個儲存庫的所有視窗共用同一個佇列。

凡是變更儲存庫的操作都是這樣，不論從哪裡發起：選單、工具列、右鍵選單、快速操作、拖放、按兩下、對話框、檔案列表和提交區。

- 儲存庫正忙時，選單項目和按鈕照樣可以用。按下對話框的按鈕後，對話框照常關閉。
- 需要你確認的操作，例如刪除分支或強制推送，在你按的時候就確認，輪到時不再問。
- 取決於當時儲存庫狀態的詢問，例如擋路的變更要不要儲藏，在輪到時出現。

變更工作區或暫存區的操作執行期間，檔案列表會變灰，即使操作是在另一個視窗裡發起的。擷取、推送等別的操作不影響檔案列表，在那裡做的操作排進佇列。

排隊等著的提交，它的提交訊息和選項在開始執行前都不能改。

## 輪到時 {#turn}

前一個操作結束、視窗重新整理完之後，Spooky 按儲存庫現在的狀態核對下一個操作，用的是決定選單項目能不能按的同一套規則。操作已經不合適了，例如它要處理的分支已經沒有了，就不會執行，它的記錄寫著 :ui[activity.skipped] 和原因。

一個操作失敗時，排在它後面的都會取消，不在失敗的結果上接著做。它們的記錄寫明是哪個操作失敗了。你自己停掉正在執行的操作時，只停這一個，後面的照常進行。

以下情況也會取消排著的操作：

- 和伺服器儲存庫的連線中斷。重新連上後也不會再執行。
- 你關閉視窗，或者在這個視窗裡開啟別的儲存庫。只取消從這個視窗發起的操作。
- 你結束 Spooky。

## 還原與重做 {#undo}

還原和重做不排隊。你發起的操作正在執行或等著時，它們無法使用，選單裡寫著 :ui[undo.reason.busy]。見 [暫時無法還原](/guide/work/undo/#blocked)。

## 自動擷取 {#auto-fetch}

[自動擷取](/guide/branches/sync/#auto-fetch) 只在儲存庫裡沒有操作執行或等待時開始。它擷取期間你發起任何操作，包括還原和重做，它都會馬上停下，讓你的操作執行。它的記錄寫著 :ui[activity.cancelled]，以及給哪個操作讓了路。

## 活動區 {#activity-area}

側邊欄底部列出視窗裡這個儲存庫的：

- 擷取、拉取、推送等要連線遠端的操作，執行期間和結束後的幾秒鐘裡都在，最新的在上面。
- 下面是在佇列裡等著的操作，先輪到的在上面。輪到之前，Git 輸出的位置寫著 :ui[activity.waitingDetail]。

每一列有進度列、停止按鈕和 Git 輸出的最後一行。最多同時露出三列，更多的捲動檢視。

- 按一下等待中那一列的停止按鈕，會把它移出佇列。什麼都不執行，這一列寫明操作已取消。
- 按一下執行中那一列的停止按鈕，會停掉這個操作。
- 按一下一列裡的其他地方，會開啟 :ui[activity.title] 視窗。

不連線遠端的操作開始執行後就離開活動區，進度顯示在視窗裡，例如工作區或提交區。

## 活動視窗 {#activity-window}

選 :ui[menu.window > activity.title]（<kbd>⌃⌘0</kbd>）。視窗裡有所有儲存庫的記錄，分三頁，在工具列裡切換：

| 頁 | 列出什麼 | 記錄留多久 |
|---|---|---|
| :ui[activity.remote] | 擷取、拉取、推送等要連線遠端的操作 | 7 天，存在你的 Mac 上 |
| :ui[activity.repository] | 別的 Git 操作，以及你發起的讀取，例如讀取提交 | 最近的 100 筆，直到結束 |
| :ui[activity.service] | 對 GitHub 和 GitLab 的請求 | 直到結束 |

::screenshot[活動視窗的遠端頁。列表裡是一個儲存庫的擷取、拉取與推送記錄，選取的是推送，右邊是它的完整記錄內容。]{name="advanced-activity" frame="window" markers="55.2,10 37.7,4.6 93.8,4.6"}

1. 三個頁面：:ui[activity.remote]、:ui[activity.repository] 與 :ui[activity.service]
2. :ui[activity.clear]
3. 搜尋框

Spooky 為了讓視窗保持最新而自己做的讀取不會列出。

選取一筆記錄，右邊會顯示它的完整記錄內容，文字可以選取和拷貝。

- 等待中的操作在這裡也會列出，寫著 :ui[activity.waiting]，帶停止按鈕。
- :ui[activity.clear] 會清掉目前頁面已經結束的記錄，進行中的留著。
- 搜尋框按儲存庫名稱和記錄內容篩選目前頁面。

記錄內容裡不會出現密碼和權杖。

## 系統通知 {#notifications}

以下情況 Spooky 會發出通知：

- 複製完成。通知寫著遠端位址（去掉了其中的使用者名稱和密碼）和複製到的位置。見 [複製儲存庫](/guide/repositories/manager/#clone)。
- 自動封存了分支。通知寫著封存了幾個。見 [自動封存](/guide/branches/review/#auto-archive)。

Spooky 不會問你要不要允許通知，所以一開始 macOS 會把通知悄悄放進 **通知中心**。想改變通知的顯示方式，選 **蘋果選單 › 系統設定**，按一下側邊欄中的 **通知**，再按一下 **Spooky**。按一下通知會把 Spooky 帶到最前面。

:::note[伺服器儲存庫]
每個伺服器儲存庫和本機儲存庫一樣，有自己的佇列。停掉操作，或者自動擷取讓路時，伺服器上的 Git 程序也會結束。
:::

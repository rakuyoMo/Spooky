---
title: "작업 대기열과 활동"
description: "Spooky가 쓰기 작업을 대기열에 넣는 방식을 알아보고, 사이드바의 활동 영역과 활동 윈도우에서 작업을 지켜보고 취소하고, 시스템 알림을 받습니다."
---

Spooky는 저장소를 한 번에 작업 하나씩 바꿉니다. 다른 작업이 실행 중일 때 무언가를 시작하면 거절되지 않고 차례를 기다립니다. 상태, 기록, Diff 불러오기는 기다리지 않습니다.

## 작업이 대기하는 방식 {#queue}

저장소에서 실행 중인 것이 없으면 작업은 바로 시작됩니다. 그렇지 않으면 저장소의 대기열에 들어가고, 작업은 시작한 순서대로 실행됩니다. 그 저장소를 보여 주는 모든 윈도우가 같은 대기열을 씁니다.

저장소를 바꾸는 모든 일이 여기에 해당하고, 어디에서 시작하든 같습니다. 메뉴, 도구 막대, 오른쪽 클릭 메뉴, 빠른 동작, 드래그 앤 드롭, 이중 클릭, 대화상자, 파일 목록, 커밋 영역이 모두 포함됩니다.

- 메뉴 항목과 버튼은 저장소가 바쁜 동안에도 쓸 수 있습니다. 대화상자는 평소처럼 버튼을 클릭하면 닫힙니다.
- 브랜치 삭제나 강제 푸시처럼 확인을 구하는 작업은 클릭할 때 묻습니다. 차례가 왔을 때 다시 묻지 않습니다.
- 방해가 되는 변경 사항을 스태시할지처럼 그 순간의 저장소에 달린 질문은 차례가 왔을 때 나옵니다.

작업 사본이나 인덱스를 바꾸는 작업이 실행되는 동안에는 파일 목록이 흐리게 표시됩니다. 다른 윈도우에서 시작한 작업이어도 그렇습니다. 가져오기나 푸시 같은 다른 작업은 파일 목록을 그대로 두고, 거기에서 하는 일은 대기열에 들어갑니다.

대기 중인 커밋은 실행될 때까지 메시지와 옵션이 잠겨 있습니다.

## 차례가 왔을 때 {#turn}

앞의 작업이 끝나고 윈도우가 새로 고쳐진 뒤, Spooky는 다음 작업을 지금의 저장소에 비추어 확인합니다. 메뉴 항목을 쓸 수 있는지 정하는 것과 같은 규칙을 씁니다. 작업 대상 브랜치가 없어진 경우처럼 작업이 더는 말이 되지 않으면 실행되지 않습니다. 기록에는 이유와 함께 :ui[activity.skipped]이라고 표시됩니다.

작업이 실패하면 그 뒤에 대기 중인 것은 모두 취소되므로, 실패 위에서 실행되는 것은 없습니다. 각 기록에는 어떤 작업이 실패했는지 표시됩니다. 실행 중인 작업을 직접 멈추면 그 작업만 멈추고 나머지는 계속됩니다.

대기 중인 작업은 다음 경우에도 취소됩니다.

- 서버 저장소와의 연결이 끊어졌을 때. 다시 연결한 뒤에도 실행되지 않습니다.
- 윈도우를 닫거나 그 윈도우에서 다른 저장소를 열 때. 그 윈도우에서 시작한 작업만 취소됩니다.
- Spooky를 종료할 때.

## 실행 취소와 실행 복귀 {#undo}

실행 취소와 실행 복귀는 대기하지 않습니다. 시작한 작업이 실행 중이거나 대기 중인 동안에는 쓸 수 없고, 메뉴에 :ui[undo.reason.busy]이라고 표시됩니다. [실행 취소가 막힐 때](/guide/work/undo/#blocked)를 참고하세요.

## 자동 가져오기 {#auto-fetch}

[자동 가져오기](/guide/branches/sync/#auto-fetch)는 저장소에서 실행 중이거나 대기 중인 것이 없을 때만 시작됩니다. 가져오는 동안 실행 취소와 실행 복귀를 포함해 무엇이든 시작하면, 자동 가져오기는 바로 멈추고 그 작업이 실행됩니다. 기록에는 :ui[activity.cancelled]이라고 표시되고, 어떤 작업에 자리를 내줬는지도 나옵니다.

## 활동 영역 {#activity-area}

사이드바 맨 아래에는 윈도우에 열린 저장소에 대해 다음이 나열됩니다.

- 가져오기, 풀, 푸시 등 원격에 연결하는 작업. 실행 중인 동안과 끝난 뒤 몇 초 동안 표시됩니다. 가장 새로운 것이 맨 위에 있습니다.
- 그 아래에는 대기열에서 기다리는 작업. 다음 차례가 맨 위에 있습니다. 차례가 올 때까지 Git의 출력 대신 :ui[activity.waitingDetail]이 표시됩니다.

행마다 진행 막대, 중지 버튼, Git 출력의 마지막 줄이 있습니다. 한 번에 세 행까지 표시됩니다. 더 보려면 스크롤합니다.

- 대기 중인 행의 중지 버튼을 클릭하면 대기열에서 빠집니다. 아무것도 실행되지 않고, 행에 작업이 취소되었다고 표시됩니다.
- 실행 중인 행의 중지 버튼을 클릭하면 작업이 멈춥니다.
- 행의 다른 곳을 클릭하면 :ui[activity.title] 윈도우가 열립니다.

원격에 연결하지 않는 작업은 시작하면 이 영역에서 빠집니다. 진행 상황은 윈도우 자체에, 예를 들어 작업 사본이나 커밋 영역에 표시됩니다.

## 활동 윈도우 {#activity-window}

:ui[menu.window > activity.title](<kbd>⌃⌘0</kbd>)을 선택합니다. 윈도우에는 모든 저장소의 기록이 있고, 도구 막대에서 고르는 세 페이지로 나뉩니다.

| 페이지 | 나열하는 것 | 기록이 남는 기간 |
|---|---|---|
| :ui[activity.remote] | 가져오기, 풀, 푸시 등 원격에 연결하는 작업 | 7일. Mac에 저장됩니다. |
| :ui[activity.repository] | 그 밖의 Git 작업과, 커밋 불러오기처럼 직접 시작한 불러오기 | 최근 100개. 종료할 때까지 |
| :ui[activity.service] | GitHub와 GitLab으로 보낸 요청 | 종료할 때까지 |

::screenshot[원격 페이지를 보여 주는 활동 윈도우. 목록에 한 저장소의 가져오기, 풀, 푸시 기록이 있습니다. 푸시가 선택되어 있고, 전체 로그가 오른쪽에 있습니다.]{name="advanced-activity" frame="window" markers="55.2,10 35.3,4.6 93.8,4.6"}

1. 페이지: :ui[activity.remote], :ui[activity.repository], :ui[activity.service]
2. :ui[activity.clear]
3. 검색 필드

Spooky가 윈도우를 최신 상태로 유지하려고 알아서 하는 불러오기는 나열되지 않습니다.

기록을 선택하면 오른쪽에 전체 로그가 표시됩니다. 텍스트는 선택해서 복사할 수 있습니다.

- 대기 중인 작업도 여기에 :ui[activity.waiting]으로 나열되고, 중지 버튼이 있습니다.
- :ui[activity.clear]는 현재 페이지의 끝난 기록을 제거합니다. 실행 중인 기록은 남습니다.
- 검색 필드는 현재 페이지를 저장소 이름과 로그 텍스트로 걸러 냅니다.

암호와 토큰은 로그에서 빠집니다.

## 시스템 알림 {#notifications}

Spooky는 다음 경우에 알림을 보냅니다.

- 복제가 끝났을 때. 사용자 이름이나 암호를 뺀 원격 주소와 저장소가 복제된 위치가 표시됩니다. [저장소 복제하기](/guide/repositories/manager/#clone)를 참고하세요.
- 브랜치가 자동으로 보관되었을 때. 개수가 표시됩니다. [자동으로 보관하기](/guide/branches/review/#auto-archive)를 참고하세요.

Spooky는 권한을 요청하지 않으므로, 처음에는 macOS가 알림을 **알림 센터**에 조용히 전달합니다. 표시 방식을 고르려면 **Apple 메뉴 › 시스템 설정**을 선택하고 사이드바에서 **알림**을 클릭한 다음 **Spooky**를 클릭합니다. 알림을 클릭하면 Spooky가 맨 앞으로 나옵니다.

:::note[서버 저장소]
서버 저장소도 로컬 저장소처럼 저장소마다 대기열이 따로 있습니다. 작업을 멈추거나 자동 가져오기가 자리를 내주면 서버의 Git 프로세스도 끝납니다.
:::

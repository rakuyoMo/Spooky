<Grid columns={4}>

<Point icon="server" title="Mac에 복제하지 않습니다">

작업 트리는 서버에 그대로 있습니다. 먼저 Mac에 복제할 필요가 없습니다.

</Point>

<Point icon="terminal" title="Git은 서버에서 실행됩니다">

Spooky는 서버에 설치된 Git을 사용하고, 파일은 SSH로 읽고 씁니다.

</Point>

<Point icon="key" title="이미 쓰고 있는 SSH 그대로">

연결에는 시스템의 SSH와 `~/.ssh/config`의 호스트 별칭을 사용합니다. 인증, 호스트 키, 연결 공유는 OpenSSH가 처리합니다.

</Point>

<Point icon="script" title="root도, 백그라운드 서비스도 필요 없습니다">

Spooky는 서버의 root 권한이 필요 없고, 백그라운드 서비스도 설치하지 않습니다. `~/.spooky/bin/`에 작은 도우미 스크립트 하나만 둡니다.

</Point>

</Grid>

<Feature
  title="호스트 별칭 하나, 경로 하나"

Spooky가 연결을 확인하고 저장소를 엽니다.

</Feature>

</Section>

브랜치를 현재 브랜치로 드래그하면 병합하고, <kbd>⌥</kbd>을 누른 채 드래그하면 그 브랜치로 리베이스합니다.

</Feature>

  ]}

충돌한 파일마다 Spooky가 양쪽의 버전을 나란히 보여 줍니다.

하나를 고르면 그 버전으로 파일을 해결하고, 둘 다 선택하면 병합 도구를 엽니다.

</Feature>

<Grid columns={4}>

<Point icon="history" title="기록과 검색">

커밋 그래프에서 모든 브랜치의 흐름을 따라갑니다. 메시지, 작성자, 커미터, 파일, 커밋 해시, 날짜로 검색합니다.

</Point>

<Point icon="undo" title="실행 취소와 실행 복귀">

커밋, 되돌리기, 스태시 등의 작업은 <kbd>⌘Z</kbd>로 실행 취소하고 <kbd>⇧⌘Z</kbd>로 실행 복귀합니다.

</Point>

<Point icon="pullRequest" title="풀 리퀘스트와 머지 리퀘스트">

GitHub, GitLab.com, <mark>자체 관리형 GitLab</mark>에서 목록을 보고, 만들고, 토론하고, 체크아웃하고, 병합하고, 닫습니다.

</Point>

<Point icon="layers" title="스태시, 하위 모듈, <mark>작업 트리</mark>, Git LFS">

모두 서버 저장소에서도 사용할 수 있습니다.

</Point>

</Grid>

<More>[So funktionieren Server-Repositorys](/guide/server/overview/)</More>

<Grid columns={4}>

<Point icon="server" title="Kein Klon auf Ihrem Mac">

Das Arbeitsverzeichnis bleibt auf dem Server. Sie müssen es nicht erst auf Ihren Mac klonen.

</Point>

<Point icon="terminal" title="Git läuft auf dem Server">

Spooky verwendet das Git des Servers und liest und schreibt Dateien per SFTP.

</Point>

<Point icon="key" title="Das SSH, das Sie schon nutzen">

Verbindungen laufen über das SSH des Systems und die Host-Aliasse in `~/.ssh/config`. OpenSSH übernimmt Authentifizierung, Host-Schlüssel und die gemeinsame Nutzung von Verbindungen.

</Point>

<Point icon="script" title="Kein Root, kein Hintergrunddienst">

Spooky braucht auf dem Server keinen Root-Zugriff und installiert keinen Hintergrunddienst. Es legt nur ein kleines Hilfsskript in `~/.spooky/bin/` ab.

</Point>

</Grid>

<Feature
  title="Ein Host-Alias und ein Pfad"
  shots={[
    {
      name: 'add-server',
      alt: 'Das Dialogfenster zum Hinzufügen eines Server-Repositorys mit dem Host-Alias spooky-test und dem Pfad /srv/git/driftwood.',
      frame: 'dialog',
    },
  ]}
>

Wählen Sie :ui[action.addRemote], geben Sie einen Host-Alias aus `~/.ssh/config` ein und tippen Sie dann den Pfad des Repositorys auf dem Server ein oder suchen Sie ihn dort aus.

Spooky prüft die Verbindung und öffnet das Repository.

</Feature>

</Section>

<Feature
  title="Branches, Synchronisation, Zusammenführen und Rebase"
  reverse
  shots={[

Abrufen, Pullen und Pushen erledigen Sie über die Symbolleiste.

Ziehen Sie einen Branch auf den aktuellen, um ihn zusammenzuführen, oder halten Sie beim Ziehen <kbd>⌥</kbd> gedrückt, um ein Rebase darauf auszuführen.

</Feature>

<Feature
  title="Ein Assistent für Konflikte"
  reveal
  shots={[
    {
      name: 'conflict',
      alt: 'Der Konfliktassistent nach einem Merge mit beiden Versionen von src/units.ts.',
      frame: 'window',
    },
  ]}
>

Für jede Datei mit Konflikten zeigt Spooky die Version jeder Seite.

Wählen Sie eine aus, um die Datei damit zu lösen, oder wählen Sie beide und öffnen Sie ein Zusammenführungswerkzeug.

</Feature>

<Grid columns={4}>

<Point icon="history" title="Verlauf und Suche">

Verfolgen Sie jeden Branch im Commit-Graphen. Suchen Sie nach Nachricht, Autor, Committer, Datei, Commit-Hash oder Datum.

</Point>

<Point icon="undo" title="Widerrufen und Wiederholen">

Commits, Reverts, Stashes und mehr lassen sich mit <kbd>⌘Z</kbd> widerrufen und mit <kbd>⇧⌘Z</kbd> wiederholen.

</Point>

<Point icon="pullRequest" title="Pull Requests und Merge Requests">

Auflisten, erstellen, diskutieren, auschecken, zusammenführen und schließen – auf GitHub, GitLab.com und <mark>selbst verwaltetem GitLab</mark>.

</Point>

<Point icon="layers" title="Stashes, Submodule, <mark>Worktrees</mark> und Git LFS">

Alles funktioniert auch in Server-Repositorys.

</Point>

</Grid>

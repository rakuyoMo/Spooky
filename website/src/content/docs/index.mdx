<More>[How server repositories work](/guide/server/overview/)</More>

<Grid columns={4}>

<Point icon="server" title="No clone on your Mac">

The working tree stays on the server. You don’t clone it to your Mac first.

</Point>

<Point icon="terminal" title="Git runs on the server">

Spooky uses the server’s own Git, and reads and writes files over SFTP.

</Point>

<Point icon="key" title="The SSH you already use">

Connections use the system’s SSH and the host aliases in `~/.ssh/config`. OpenSSH handles authentication, host keys, and connection sharing.

</Point>

<Point icon="script" title="No root, no background service">

Spooky needs no root access on the server and installs no background service. It keeps just a small helper script in `~/.spooky/bin/`.

</Point>

</Grid>

<Feature
  title="A host alias and a path"

Choose :ui[action.addRemote], enter a host alias from `~/.ssh/config`, then type or browse to the repository’s path on the server.

Spooky checks the connection and opens the repository.

</Feature>

Pick one to resolve the file with it, or select both and open a merge tool.

</Point>

<Point icon="undo" title="Undo and redo">

</Point>

<More> [サーバーリポジトリの仕組み](/guide/server/overview/) </More>

<Grid columns={4}>

<Point icon="server" title="Mac にクローンしない">

作業ツリーはサーバーに置いたままです。先に Mac へクローンする必要はありません。

</Point>

<Point icon="terminal" title="Git はサーバーで動く">

Spooky はサーバーの Git を使い、ファイルは SFTP で読み書きします。

</Point>

<Point icon="key" title="いつもの SSH をそのまま">

接続にはシステムの SSH と `~/.ssh/config` のホストエイリアスを使います。認証、ホスト鍵、接続の共有は OpenSSH に任せます。

</Point>

<Point icon="script" title="root もバックグラウンドサービスも不要">

サーバーの root 権限は要りません。バックグラウンドサービスもインストールしません。Spooky が置くのは `~/.spooky/bin/` の小さなヘルパースクリプトだけです。

</Point>

</Grid>

:ui[action.addRemote] を選び、`~/.ssh/config` のホストエイリアスを入力して、サーバー上のリポジトリのパスを入力するかブラウズして選びます。

Spooky が接続を確認して、リポジトリを開きます。

</Feature>

<Feature
  title="ブランチ、同期、マージ、リベース"
  reverse
  shots={[
    { name: 'branches', alt: 'サイドバーのブランチのセクション。', frame: 'closeup' },
    { name: 'sync', alt: 'プッシュのダイアログ。main を origin/main にプッシュします。', frame: 'dialog' },
  ]}
>

フェッチ、プル、プッシュはツールバーから行えます。

ブランチを現在のブランチにドラッグするとマージ、<kbd>⌥</kbd> を押しながらドラッグするとそのブランチへのリベースになります。

</Feature>

<Feature
  title="競合はウィザードで"
  reveal
  shots={[
    {
      name: 'conflict',
      alt: 'マージ後の競合ウィザード。src/units.ts の両側のバージョンが並んでいます。',
      frame: 'window',
    },
  ]}
>

競合したファイルごとに、Spooky が両側のバージョンを並べて表示します。

片方を選べばそのバージョンで解決し、両方を選べばマージツールで開けます。

</Feature>

<Grid columns={4}>

<Point icon="history" title="履歴と検索">

コミットグラフですべてのブランチの流れを追えます。メッセージ、作成者、コミッター、ファイル、コミットハッシュ、日付で検索できます。

</Point>

<Point icon="undo" title="取り消しとやり直し">

コミット、リバート、スタッシュなどの操作は <kbd>⌘Z</kbd> で取り消し、<kbd>⇧⌘Z</kbd> でやり直せます。

</Point>

<Point icon="pullRequest" title="プルリクエストとマージリクエスト">

GitHub、GitLab.com、<mark>セルフマネージドの GitLab</mark> で、一覧、作成、議論、チェックアウト、マージ、クローズができます。

</Point>

<Point icon="layers" title="スタッシュ、サブモジュール、<mark>ワークツリー</mark>、Git LFS">

どれもサーバーリポジトリでも使えます。

</Point>

</Grid>

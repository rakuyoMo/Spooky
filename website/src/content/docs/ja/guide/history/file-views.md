ここで説明するビューは、一度に 1 つのファイルを扱います。そのファイルを変更したコミット、各行を誰が書いたか、過去のある時点でどういう内容だったかを確認できます。

## ファイル履歴 {#file-history}

ファイルを変更したすべてのコミットを表示するには、次のようにします。

- 作業コピーでファイルを右クリックし、:ui[fileHistory.showHistoryOf]{1="units.ts"} を選びます。
- または、右のカラムの上部にあるファイル名にポインタを合わせ、:ui[fileHistory.title] をクリックします。
- [コミットの詳細](/guide/history/commit-details/#changeset) で、変更セットまたはファイルツリーのファイルを右クリックし、同じ項目を選びます。

作業コピーでは、フォルダを選択して、右のカラムの上部にある :ui[fileHistory.title] をクリックすることもできます。この場合、履歴はフォルダ内のすべてのファイルが対象になります。

左のカラムには、コミットが新しいものから順に、月ごとにまとめて並びます。上部にはファイル名とコミットの数が表示されます。ファイル名をクリックすると、別のファイルに切り替えられます。

コミットを選択すると、そのコミットがファイルに加えた変更が右側に表示されます。:ui[showFile.raw] に切り替えると、そのコミットの時点でのファイル全体が表示され、:ui[fileHistory.diff] で元に戻ります。上部の短いハッシュにポインタを合わせると、さらに次のボタンが表示されます。

- :ui[blame.title] は、そのコミットの時点で各行を誰が書いたかを表示します。[Blame](#blame) を参照してください。
- :ui[fileHistory.showCommit] は、コミットをウインドウ全体に表示します。[詳細をウインドウ全体に表示する](/guide/history/commit-details/#full-page) を参照してください。
- :ui[externalTool.action.diffTool] は、変更を比較ツールで開きます。

::screenshot[src/units.ts のファイル履歴。左のカラムにファイル名とコミットの数が表示され、このファイルを変更したコミットが月ごとにまとめられています。右側には、選択中のコミットがファイルに加えた変更が表示されています。ポインタは短いハッシュの上にあります。右上には、Diff と原文の切り替えの横に、Blame、コミットを表示、比較ツールのボタンが表示されています。]{name="history-file-history" frame="window" markers="28.5,9 94.6,13.25 86,13.25"}

1. ファイル名とコミットの数
2. :ui[fileHistory.diff] と :ui[showFile.raw] の切り替え
3. ポインタが短いハッシュの上にある間に表示されるボタン

コミットをダブルクリックするか <kbd>Return</kbd> を押しても、ウインドウ全体の詳細で開きます。コミットを右クリックすると、同じ操作に加えて、そのコミットの時点でのファイルの復元と書き出しができます。

### ファイル履歴を検索する {#file-history-search}

ツールバーの検索フィールドに入力すると、一覧が絞り込まれます。フィールド内の虫眼鏡をクリックして、検索する対象を選びます：:ui[fileHistory.scope.message]、:ui[fileHistory.scope.hash]、:ui[fileHistory.scope.author]、:ui[fileHistory.scope.committer]。

- メッセージ、作成者、コミッタは、入力したテキストに大文字と小文字を区別せずに一致します。作成者とコミッタは、名前またはメールアドレスで一致します。
- コミットのハッシュ、ブランチ、タグを指定すると、その時点までにファイルを変更した最新のコミットが表示されます。

## Blame {#blame}

Blame はファイル全体を表示し、右側の列に、それぞれの行のブロックを最後に変更したコミットを示します。それぞれのブロックには、作成者の画像、コミットメッセージの 1 行目、作成者、どのくらい前かが表示されます。

- 作業コピーでファイルを右クリックし、:ui[blame.show]{1="units.ts"} を選びます。または、右のカラムの上部にあるファイル名にポインタを合わせ、:ui[blame.title] をクリックします。
- コミットの変更セットまたはファイルツリーで :ui[fileHistory.blameAt]{1="units.ts" 2="e2dda2bc"} を選ぶと、その時点でのファイルが表示されます。

::screenshot[src/units.ts の Blame。左側にファイルがあります。右側の列には、それぞれのブロックを最後に変更したコミットの画像、メッセージ、作成者、経過時間が表示されています。Drop trailing zeros from temperatures のブロックが強調表示されています。]{name="history-blame" frame="window" markers="84,22 84,82.5"}

1. それぞれのブロックを最後に変更したコミットを示す列
2. クリックしたコミットの、強調表示されたブロック

ブロックをクリックすると、そのコミットの概要が表示されます。同じコミットのブロックがすべて強調表示されます。ブロックをダブルクリックすると、そのコミットがウインドウ全体の詳細で開きます。列の幅を変えるには、左端をドラッグします。幅は記憶されます。

Blame には、すでにコミットされているファイルが必要です。新しいファイル、未追跡のファイル、バイナリファイル、サブモジュールは表示できません。

## あるリビジョンの時点でのファイルを表示する {#show-file}

作業コピーを変更せずに、任意のコミットの時点でのファイルを読むには、次のようにします。

- 作業コピーでファイルを右クリックし、:ui[showFile.show]{1="units.ts"} を選びます。HEAD のバージョンが表示されます。
- コミットの変更セットまたはファイルツリーで、:ui[fileHistory.showAt]{1="units.ts" 2="e2dda2bc"} を選びます。

ヘッダは「リビジョン › ファイル」というパスのように表示されます。

- リビジョンをクリックすると、別のコミットを選べます。一覧でコミットをダブルクリックすると、そのコミットに切り替わります。
- ファイル名をクリックすると、同じコミットの別のファイルを選べます。
- :ui[showFile.raw] と :ui[blame.title] で、ファイルそのものの表示と [Blame](#blame) を切り替えます。
- ヘッダにポインタを合わせると、:ui[fileHistory.title] と :ui[fileHistory.showCommit] が表示されます。

ヘッダの下には、このファイルを変更したことのある人の数が、その画像と一緒に表示されます。テキストには、テーマと、:ui[app.name > settings.title] › :ui[settings.text] の設定が使われます。[テキスト](/guide/settings/appearance/#text) を参照してください。

Blame と同じく、このビューでも新しいファイル、未追跡のファイル、バイナリファイル、サブモジュールは表示できません。

## リビジョンからファイルを復元する {#restore}

ファイルを以前のコミットの時点の状態に戻すには、次のようにします。

1. ファイル履歴でコミットを右クリックし、メニューから :ui[fileHistory.restoreAt]{1="units.ts" 2="e2dda2bc"} を選びます。[コミットの詳細](/guide/history/commit-details/#changeset) では、項目は :ui[fileHistory.restoreInWorkingCopy]{1="units.ts" 2="e2dda2bc"} になります。
2. Spooky が先に確認を求めます。:ui[fileHistory.restore.submit] をクリックします。

ファイルのステージ済みの変更と未ステージの変更は、どちらも置き換えられます。そのコミットにファイルが存在しなかった場合、ファイルは削除されます。コミットは行われず、復元されたファイルはステージ済みの変更として作業コピーに表示されます。

元に戻すには、:ui[menu.edit > menu.undo]（<kbd>⌘Z</kbd>）を選びます。

変更セットまたはファイルツリーからは、複数のファイルやフォルダを一度に復元できます。

:::note[サーバリポジトリ]
ファイルはサーバ上で上書きされます。次回から確認を省くには、:ui[dialog.doNotAskAgain] を選択します。もう一度確認されるようにするには、:ui[app.name > settings.title] › :ui[settings.general] で :ui[settings.warnRestoringOnServer] をオンにします。[確認](/guide/settings/general/#confirmations) を参照してください。
:::

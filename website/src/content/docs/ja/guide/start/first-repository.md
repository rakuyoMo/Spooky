title: "最初のリポジトリ"
description: "Mac 上のリポジトリを開き、変更、ステージ、コミット、プッシュまでをひととおり行います。"

このページでは、作業をひととおり最後まで行います。Mac 上のリポジトリを開き、ファイルを変更し、変更をステージしてコミットし、コミットをリモートにプッシュします。

プッシュできるリモートのある Git リポジトリが Mac 上に必要です。まだない場合は、[リポジトリウインドウ](/guide/repositories/manager/) でクローンまたは作成の方法を確認してください。

## リポジトリを開く {#open}

1. :ui[menu.file > action.openLocal]（<kbd>⌘O</kbd>）を選びます。
2. リポジトリのフォルダを選択して、:ui[repositories.panel.prompt] をクリックします。

Spooky がリポジトリを開き、:ui[workspace.title] を表示します。リポジトリは「リポジトリ」の一覧にも追加されます。次回からはそこから開けます。

リポジトリ内のフォルダならどれを選んでもかまいません。Spooky はリポジトリ全体を開きます。フォルダが Git リポジトリの中にない場合は、:ui[bookmarks.noRepository.title] と表示されます。:ui[bookmarks.noRepository.create] をクリックするとそのフォルダが新しいリポジトリになり、:ui[action.cancel] をクリックすると別のフォルダを選び直せます。

:::note[サーバリポジトリ]
サーバ上のリポジトリで作業するときは、代わりに :ui[action.addRemote] で追加します。手順は [サーバリポジトリを追加する](/guide/server/add/) で説明しています。開いたあとは、このページの残りの手順は同じです。
:::

## 変更を加える {#change}

好きなエディタでリポジトリ内のファイルを編集して保存します。Spooky が変更に気づき、:ui[workspace.title] にそのファイルを表示します。変更が表示されないときは、:ui[action.refresh] をクリックするか <kbd>⌘R</kbd> を押します。

ファイルを選択すると、右のカラムに変更内容が表示されます。追加された行は緑、削除された行は赤です。

## 変更をステージする {#stage}

Git は変更したものをすべてコミットするわけではありません。コミットされるのはステージしたものだけです。ステージすることで、次のコミットに入れる変更を選べます。それ以外は作業コピーに残り、あとで扱えます。

ファイルをステージするには、次のいずれかを行います。

- ファイルの前にあるチェックボックスを選択します。
- 1 つ以上のファイルを選択して <kbd>スペース</kbd> を押します。
- :ui[working.stageAll] をクリックして、変更されたファイルをすべてステージします。

ステージ済みのファイルはチェックボックスが選択されたままになります。ファイルの一部の行だけをステージするには、[変更を確認してステージする](/guide/work/diff/) を参照してください。

## コミットする {#commit}

コミットは、ステージした変更をリポジトリの履歴に保存します。何をなぜ変更したかを書いたメッセージが付きます。

1. :ui[working.subject] をクリックして、変更の短い要約を入力します。入力中はコミットエリアが広がります。
2. さらに説明したいときは、:ui[working.body] に書きます。
3. :ui[working.commit] をクリックするか、<kbd>⌘↩</kbd> を押します。

::screenshot[件名に「Add gust alerts and a humidity chart」と入力したコミットエリア。その下に、空の詳細な説明、「直前のコミットを修正」と「サインオフ」のチェックボックス、作成者の名前とメールアドレス、「すべてステージ」と「コミット」のボタンがあります。下のファイル一覧では 3 つのファイルのチェックボックスが選択されています。]{name="start-commit" frame="closeup"}

広がったコミットエリアについて、いくつか補足します。

- 件名フィールドの末尾の数字は、残りの文字数です。これを超えると、件名は推奨より長くなります。
- 件名に何か入力するまで、:ui[working.commit] は淡色表示のままです。
- 右側の名前とメールアドレスは、作成者としてコミットに記録されます。変更するには、[ユーザプロファイルと Git 設定](/guide/settings/identity/) を参照してください。
- :ui[working.amend] と :ui[commit.signOff] は [変更をコミットする](/guide/work/commit/) で説明しています。

コミットすると、コミットしたファイルは一覧から消えます。サイドバーでは、現在のブランチに ↑1 と表示されます。Mac 上にあって、まだリモートにないコミットが 1 つあるという意味です。

## プッシュする {#push}

プッシュは、コミットをリモートに送ります。ほかの人はそこからコミットを取得でき、リモートにはバックアップとしてコピーが残ります。

1. ツールバーの :ui[sync.push] をクリックするか、:ui[menu.repository > sync.pushMenu]（<kbd>⇧⌘U</kbd>）を選びます。
2. :ui[sync.destination] がプッシュ先のリモートブランチになっていることを確認します。ブランチがすでにリモートブランチを追跡している場合は、そのブランチが選択されています。
3. :ui[sync.pushHead] をクリックします。

::screenshot[HEAD をプッシュするダイアログ。ローカルブランチ「main」の新しいコミットを、プッシュ先の origin/main にプッシュします。下には、折りたたまれた「オプション」セクションと、「キャンセル」「HEAD をプッシュ」のボタンがあります。]{name="sync" frame="dialog"}

プッシュが終わると、ブランチの横の ↑1 が消えます。:ui[dialog.options] については [プッシュ](/guide/branches/sync/#push) で説明しています。ブランチを初めてプッシュするときは、[ブランチを公開する](/guide/branches/sync/#publish) を参照してください。

:::tip
<kbd>⌥</kbd> を押しながら :ui[sync.push] ボタンをクリックします。ボタンが :ui[sync.quickPush] に変わり、ダイアログなしで現在のブランチをすぐ追跡ブランチにプッシュします。
:::

Spooky は、リポジトリを一度に 1 つの操作で変更します。別の操作の実行中に何かを始めると、拒否されるのではなく、順番を待ちます。状態、履歴、差分の読み込みは待たされません。

## 操作がキューに入る仕組み {#queue}

リポジトリで何も実行されていないときは、操作はすぐに始まります。そうでないときはリポジトリのキューに入り、操作は始めた順に実行されます。同じリポジトリを表示しているすべてのウインドウが、同じキューを共有します。

リポジトリを変更する操作は、どこから始めてもすべて対象になります。メニュー、ツールバー、右クリックメニュー、クイックアクション、ドラッグ＆ドロップ、ダブルクリック、ダイアログ、ファイル一覧、コミットエリアです。

- リポジトリがビジーの間も、メニュー項目とボタンは使えます。ダイアログは、いつもどおりボタンをクリックすると閉じます。
- ブランチの削除や強制プッシュのように確認が必要な操作は、クリックしたときに確認を求めます。順番が来たときにもう一度尋ねることはありません。
- 妨げになる変更をスタッシュするかどうかなど、その時点のリポジトリの状態で決まる確認は、順番が来たときに表示されます。

作業コピーまたはインデックスを変更する操作の実行中は、別のウインドウで始めた操作であっても、ファイル一覧が淡く表示されます。フェッチやプッシュなどそのほかの操作ではファイル一覧はそのままで、そこで行った操作はキューに入ります。

待機中のコミットは、実行されるまでメッセージとオプションがロックされます。

## 順番が来たとき {#turn}

前の操作が終わってウインドウが更新されると、Spooky は次の操作をいまのリポジトリの状態に照らして確認します。メニュー項目が使えるかどうかを決めるのと同じルールを使います。対象のブランチがなくなっているなど、操作が意味をなさなくなっている場合は実行されません。その記録には、理由とともに :ui[activity.skipped] と表示されます。

操作が失敗すると、そのあとのキューにある操作はすべてキャンセルされ、失敗した状態の上で何かが実行されることはありません。それらの記録には、どの操作が失敗したかが表示されます。実行中の操作を自分で停止した場合は、その操作だけが止まり、残りは続きます。

キューにある操作は、次の場合にもキャンセルされます。

- サーバリポジトリとの接続が切れた場合。再接続しても実行されません。
- ウインドウを閉じた場合、またはそのウインドウで別のリポジトリを開いた場合。そのウインドウから始めた操作だけがキャンセルされます。
- Spooky を終了した場合。

## 取り消しとやり直し {#undo}

取り消しとやり直しはキューに入りません。自分で始めた操作が実行中または待機中の間は使えず、メニューには :ui[undo.reason.busy] と表示されます。[取り消しができないとき](/guide/work/undo/#blocked) を参照してください。

## 自動フェッチ {#auto-fetch}

[自動フェッチ](/guide/branches/sync/#auto-fetch) は、リポジトリで何も実行されておらず、待機中の操作もないときにだけ始まります。フェッチ中に何かを始めると、取り消しとやり直しも含めて、自動フェッチはすぐに止まり、その操作が実行されます。記録には、:ui[activity.cancelled] と、どの操作に譲ったかが表示されます。

## アクティビティエリア {#activity-area}

サイドバー下部には、ウインドウに表示しているリポジトリについて、次のものが並びます。

- フェッチ、プル、プッシュなど、リモートに接続する操作。実行中と、完了後の数秒間表示されます。新しいものが上に来ます。
- その下に、キューで待機中の操作。次に実行されるものが上に来ます。順番が来るまで、Git の出力の代わりに :ui[activity.waitingDetail] と表示されます。

それぞれの行には、進行状況バー、停止ボタン、Git の出力の最後の行が表示されます。一度に表示されるのは 3 行までで、スクロールすると残りが見られます。

- 待機中の行の停止ボタンをクリックすると、その操作がキューから外れます。何も実行されず、行には操作がキャンセルされたことが表示されます。
- 実行中の行の停止ボタンをクリックすると、その操作が停止します。
- 行のそれ以外の場所をクリックすると、:ui[activity.title] ウインドウが開きます。

リモートに接続しない操作は、始まるとこのエリアから消えます。その進行状況は、作業コピーやコミットエリアなど、ウインドウの中に表示されます。

## アクティビティウインドウ {#activity-window}

:ui[menu.window > activity.title]（<kbd>⌃⌘0</kbd>）を選びます。このウインドウにはすべてのリポジトリの記録があり、ツールバーで選ぶ 3 つのページに分かれています。

| ページ | 表示される内容 | 記録が残る期間 |
|---|---|---|
| :ui[activity.remote] | フェッチ、プル、プッシュなど、リモートに接続する操作 | 7 日間。Mac に保存されます |
| :ui[activity.repository] | そのほかの Git 操作と、コミットの読み込みなど自分で始めた読み込み | 直近の 100 件。終了するまで |
| :ui[activity.service] | GitHub と GitLab へのリクエスト | 終了するまで |

::screenshot[「リモート」ページを表示したアクティビティウインドウ。一覧には、あるリポジトリのフェッチ、プル、プッシュの記録があります。プッシュが選択されていて、その完全なログが右側に表示されています。]{name="advanced-activity" frame="window" markers="56.2,10 32.8,4.6 93.8,4.6"}

1. ページ：:ui[activity.remote]、:ui[activity.repository]、:ui[activity.service]
2. :ui[activity.clear]
3. 検索フィールド

ウインドウを最新の状態に保つために Spooky が自動で行う読み込みは、表示されません。

記録を選択すると、その完全なログが右側に表示されます。テキストは選択してコピーできます。

- 待機中の操作も、停止ボタン付きで :ui[activity.waiting] としてここに表示されます。
- :ui[activity.clear] は、現在のページの完了した記録を削除します。実行中のものは残ります。
- 検索フィールドは、現在のページをリポジトリ名とログのテキストで絞り込みます。

パスワードとトークンは、ログに含まれません。

## システム通知 {#notifications}

Spooky は、次のときに通知を出します。

- クローンが完了したとき。ユーザ名やパスワードを除いたリモートのアドレスと、リポジトリのクローン先が表示されます。[リポジトリをクローンする](/guide/repositories/manager/#clone) を参照してください。
- ブランチが自動でアーカイブされたとき。その数が表示されます。[自動でアーカイブする](/guide/branches/review/#auto-archive) を参照してください。

Spooky は許可を求めないため、macOS は最初、通知を目立たない形で **通知センター** に届けます。表示方法を選ぶには、**アップルメニュー › システム設定** を選び、サイドバーの **通知** をクリックしてから、**Spooky** をクリックします。通知をクリックすると、Spooky が最前面に表示されます。

:::note[サーバリポジトリ]
サーバリポジトリにも、ローカルのリポジトリと同じように、それぞれ専用のキューがあります。操作を停止したとき、または自動フェッチが譲ったときは、サーバ上の Git プロセスも終了します。
:::

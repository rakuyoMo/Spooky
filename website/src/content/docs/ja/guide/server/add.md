サーバリポジトリを追加すると、「リポジトリ」の一覧に入り、そのまま開きます。Spooky は先に接続をチェックします。足りないものがあれば、何を直せばよいかがダイアログに表示されます。

始める前に、ターミナルが何も尋ねずにサーバに接続できることを確認してください。[SSH を準備する](/guide/server/prepare-ssh/) を参照してください。

ダイアログを開くには、:ui[menu.file] メニュー、またはリポジトリウインドウの追加ボタンのメニューから :ui[action.addRemote] を選びます。

## ダイアログに入力する {#dialog}

::screenshot[サーバリポジトリを追加するダイアログ。ホストエイリアスは spooky-test です。リポジトリのパスは /srv/git/driftwood で、横に参照ボタンがあります。この Mac へのマウントは「マウントしない」になっています。ボタンは「キャンセル」と「開く」です。]{name="add-server" frame="dialog"}

| フィールド | 入力する内容 |
|---|---|
| :ui[remote.host] | `~/.ssh/config` の `Host` の名前。`driftwood-server` など。ユーザ名やポートは付けず、エイリアスだけを入力します。エイリアスがまだないときは、[ホストエイリアスを追加する](/guide/server/prepare-ssh/#alias) を参照してください。 |
| :ui[remote.path] | サーバ上のリポジトリのフルパス。`/` で始まります。`/srv/git/driftwood` など |
| :ui[remote.mount] | 省略できます。リポジトリのフォルダをこの Mac で使えるようにして、Finder で表示できるようにします。[追加時にマウントする](/guide/server/local-location/#when-adding) を参照してください。 |

パスがわからないときは、ホストエイリアスを入力してから :ui[clone.browse] をクリックします。Spooky がサーバ上のフォルダを一覧にします。入力したパスから始まり、入力していなければサーバのホームフォルダから始まります。Git リポジトリには :ui[browse.repository] と表示されます。読み取れないフォルダは淡色表示になります。フォルダをダブルクリックして中に入り、:ui[bookmarks.create.choosePrompt] をクリックします。

リポジトリの中のフォルダを選ぶこともできます。Spooky は、そのフォルダが属するリポジトリを開きます。

:ui[action.open] は、ホストエイリアスが入力されていて、パスが `/` で始まっていると使えます。

## 接続チェック {#check}

:ui[action.open] をクリックすると、Spooky はダイアログの下部に :ui[remote.checking] と表示し、次のことを順にチェックします。

1. SSH がホストエイリアスでログインできる。
2. サーバに Git があり、バージョンが 2.41.0 以降である。
3. フォルダが存在し、開いて読み取れる。
4. フォルダが Git リポジトリの中にあり、Git がその状態を読み取れる。

チェックの間、フィールドはロックされます。:ui[action.cancel] をクリックすると、チェックを止めてダイアログを閉じます。

すべてに通ると、Spooky はサーバにヘルパーを設定し、リポジトリを「リポジトリ」の一覧に追加して開きます。

## チェックに失敗したとき {#results}

ダイアログは開いたままで、入力した内容も残ります。下部には、直す内容と、それに続いて SSH または Git の元の出力が表示されます。問題を直して、もう一度 :ui[action.open] をクリックします。

| 問題 | 対処 |
|---|---|
| ホストエイリアスが正しくない | `Host` の行のエイリアスだけを入力します。スペース、`@`、`:`、`/` は含めません。 |
| サーバのフィンガープリントが不明 | ターミナルで一度接続して、フィンガープリントを確認します。[一度接続する](/guide/server/prepare-ssh/#fingerprint) を参照してください。Spooky が代わりにフィンガープリントを受け入れることはありません。 |
| サーバのフィンガープリントが変わった | まだ接続しないでください。先にサーバの管理者に変更を確認します。 |
| SSH でログインできない | サーバが鍵を受け付けていないか、Mac が鍵のロックを解除できません。[Spooky と同じ方法で接続を試す](/guide/server/prepare-ssh/#test) を参照してください。 |
| サーバにアクセスできない | ホストエイリアスとネットワークを確認して、もう一度試します。 |
| Git が見つからない | サーバに Git 2.41.0 以降をインストールします。インストール済みの場合は、SSH でログインしたときに見つかっていません。出力には、サーバが使う `PATH` が表示されます。サーバのシェルの起動ファイルで、そこに Git のフォルダを追加します。 |
| Git が古すぎる | サーバの Git を 2.41.0 以降にアップデートします。 |
| フォルダが存在しない | パスを確認します。そこに新しいリポジトリを作るには、:ui[bookmarks.noRepository.create] をクリックします。 |
| フォルダのアクセス権がない | サーバのユーザに、フォルダを開いて読み取るアクセス権が必要です。 |
| サーバの macOS がフォルダをブロックしている | サーバが Mac で、リポジトリが「書類」などの保護されたフォルダにあります。[Mac をサーバとして使う](/guide/server/prepare-ssh/#mac-server) のとおりにリモートユーザのフルディスクアクセスをオンにするか、リポジトリを移動します。 |
| フォルダが Git リポジトリではない | リポジトリのフォルダを選ぶか、:ui[bookmarks.noRepository.create] をクリックしてこのフォルダをリポジトリにします。Git の出力が所有権に触れているときは、フォルダがサーバの別のユーザのものです。 |
| Git が状態を読み取れない | 下に表示される Git の出力に理由が書かれています。 |
| サーバのセッションを設定できない | サーバの SSH が Unix ソケットの転送を許可している必要があります。サーバには `/usr/bin/perl` も必要で、`~/.spooky/bin` と `/tmp` への書き込み権限も必要です。[システム要件](/reference/requirements/#servers) を参照してください。 |

::screenshot[サーバリポジトリを追加するダイアログ。ホストエイリアスは spooky-test、パスは /srv/git/driftwood です。フィールドの下に、選択したサーバに絶対パスが存在するか確認するよう求める警告があり、続いて元の出力「Directory does not exist」が表示されています。ボタンは「キャンセル」「リポジトリを作成」「開く」です。]{name="server-add-error" frame="dialog"}

:ui[bookmarks.noRepository.create] は、そのフォルダで `git init` を実行します。フォルダがなければ先に作成します。そのあと Spooky がもう一度接続をチェックし、新しいリポジトリを開きます。

リポジトリを追加せずに、サーバが使う `PATH` と Git を確認するには、:ui[app.name > settings.title] › :ui[settings.environment] を開きます。下部にホストエイリアスを入力して、:ui[settings.environment.server.check] をクリックします。[サーバを確認する](/guide/settings/general/#server-check) を参照してください。

## サーバの Git 環境変数 {#environment}

チェックのあと、Spooky が :ui[remote.environment.title] と表示することがあります。サーバの非対話シェルが、名前が `GIT_` で始まる変数を設定しています。これらの変数は、Spooky がサーバで実行するすべてのコマンドで、Git がリポジトリを探す方法と設定を読む方法を変えます。

:ui[action.close] をクリックすると、リポジトリが開きます。そこで Git が予想と違う動きをするときは、サーバのシェルの起動ファイルからこれらの変数を取り除いてください。

## サーバ上でクローンと検索をする {#clone-scan}

サーバリポジトリを一覧に入れる方法は、ほかに 2 つあります。

- **クローン：** クローンのダイアログの :ui[clone.to] でサーバを選びます。Git がサーバ上でリポジトリをクローンし、Spooky がサーバリポジトリとして追加します。[リポジトリをクローンする](/guide/repositories/manager/#clone) を参照してください。
- **検索：** 追加ボタンのメニューから :ui[scan.menu] を選び、:ui[scan.in] でサーバを選びます。Spooky がサーバ上のフォルダを検索し、見つけたリポジトリを一覧にします。[リポジトリを検索する](/guide/repositories/manager/#scan) を参照してください。

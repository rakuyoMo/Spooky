サーバリポジトリは、別のマシンにある Git リポジトリを Spooky が SSH 経由で開くものです。ファイルはサーバに置いたままで、Git もサーバで動きます。先に Mac へクローンする必要はありません。このページでは、それぞれの側が何をするか、Spooky がサーバに何を残すか、この Mac 上のリポジトリと何が違うかを説明します。

設定するには、まず [SSH を準備する](/guide/server/prepare-ssh/)、次に [サーバリポジトリを追加する](/guide/server/add/) を読んでください。

## どこで何が行われるか {#where}

Spooky は macOS に付属する SSH で接続します。`~/.ssh/config` ファイルのホストエイリアスを使うので、ターミナルの `ssh` コマンドと同じ方法でサーバにログインします。

サーバ側：

- Git がすべてのコマンドを実行します。サーバ自身の Git と環境を使います。
- Spooky は SFTP でファイルを読み書きします。SFTP は SSH のファイル転送機能です。
- 削除したファイルと、破棄した新規ファイルは、サーバにゴミ箱があればそこに入ります。
- フェッチ、プル、プッシュは、サーバから GitHub などのリモートにアクセスします。サーバのネットワークと、サーバの SSH 鍵を使います。

Mac 側：

- 作業に使うウインドウ、一覧、差分。
- サーバへの SSH 接続。Spooky は開いているリポジトリごとに接続を 1 つ保ち、すべてのコマンドをその接続で送ります。
- パスワードや鍵のパスフレーズなど、サーバの Git からの質問。[パスワードとパスフレーズの入力](/guide/server/connection/#prompts) を参照してください。
- アカウントへのサインインやプルリクエストの読み込みなど、GitHub と GitLab へのリクエスト。
- クイックルックやほかのアプリケーションで開くファイルのコピー。

:::note
SSH でアクセスするリモートの場合、サーバがそのリモートのホスト鍵をすでに知っている必要があります。知らないときは、サーバにログインして、そこから一度リモートに接続してください。
:::

## Spooky がサーバに残すもの {#on-server}

Spooky は管理者権限を必要としません。サービスもインストールしません。サーバに残すのは次の 2 つです。

- **`~/.spooky/bin/` のヘルパースクリプト**。サーバのホームフォルダの中にあります。Git の質問を Mac に渡します。Spooky は接続時にこれを置き、以降の接続でも使います。このフォルダにある、`-askpass` や `-gpg` などで終わるほかの名前は、同じファイルへのリンクです。
- **`/tmp/spooky-*` の一時ファイル**。リポジトリを開いている間だけあります。リポジトリを閉じると Spooky が削除します。

ヘルパーは `/usr/bin/perl` で動きます。ほとんどの macOS サーバと Linux サーバにすでに入っています。すべての要件は [システム要件](/reference/requirements/#servers) を参照してください。

`~/.spooky` はいつ削除してもかまいません。次に接続するとき、Spooky がヘルパーをもう一度インストールします。

## サーバリポジトリの違い {#differences}

サーバリポジトリは、この Mac 上のリポジトリと同じ種類のウインドウで開きます。ほとんどのビューとコマンドは同じように使えます。リポジトリがサーバにあることは、次の表示でわかります。

::screenshot[サーバリポジトリのウインドウ。タイトルは spooky-test:driftwood で、その下に現在のビューとブランチが表示されています。ツールバーにはホストエイリアス spooky-test が表示されています。中央のカラムの上部には「spooky-test: 接続済み」と書かれた帯があります。その下にコミットエリアと変更されたファイルの一覧があります。右のカラムには、選択したファイルの変更が表示されています。]{name="hero" frame="window" markers="45.8,3.3 64.4,7.2 40,8.9"}

1. ウインドウのタイトルは、`driftwood-server:driftwood` のようにホストエイリアスで始まります。リポジトリウインドウでも、名前は同じ形で表示されます。
2. ツールバーの :ui[toolbar.host] 項目に、ホストエイリアスが表示されます。
3. 作業コピー、履歴などの一覧の上部に、接続状態が表示されます。[接続状態と再接続](/guide/server/connection/) を参照してください。

動作が異なるものもあります。

| 項目 | サーバリポジトリの場合 |
|---|---|
| サーバ上で行われた変更 | Spooky は、リポジトリのウインドウが手前にある間は 2 秒ごと、それ以外は 10 秒ごとに、サーバの変更を確認します。サーバの応答が遅いときは、確認の間隔が長くなります。 |
| 接続が切れたとき | Spooky が最後に読み込んだ内容は引き続き見られますが、再接続するまで何も変更できません。 |
| :ui[action.revealFinder] | Finder で表示するには、サーバのファイルが見える Mac 上のフォルダが必要です。[この Mac 上の場所](/guide/server/local-location/) を参照してください。 |
| :ui[action.openTerminal] | ターミナルが `ssh` でサーバにログインし、リポジトリのフォルダに移動します。 |
| :ui[action.copyPath] | コピーされるパスは、`driftwood-server:/srv/git/driftwood` のようにホストエイリアスで始まります。 |
| ほかのアプリケーションでファイルを開く | ほとんどのアプリケーションには、ファイルのコピーが渡されます。保存すると、Spooky が変更をサーバに書き戻します。[ターミナルとほかのアプリケーション](/guide/server/local-location/#terminal) を参照してください。 |
| ファイルの破棄と削除 | 変更を破棄する前に、Spooky が確認します。サーバ上のファイルを上書きするためです。削除したファイルと破棄した新規ファイルは、サーバのゴミ箱に入ります。サーバにゴミ箱がないときは、Spooky が確認してから完全に削除します。 |
| :ui[settings.environment] の設定 | この Mac 上の Git にだけ適用されます。サーバの Git は、サーバ自身の環境を使います。[環境](/guide/settings/general/#environment) を参照してください。 |

変更の破棄、ファイルの完全な削除、ファイルの復元の確認は、:ui[app.name > settings.title] › :ui[settings.general] でオフにできます。[確認](/guide/settings/general/#confirmations) を参照してください。

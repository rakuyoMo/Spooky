---
title: "取り消しと復元"
description: "⌘Z で取り消せる操作と、取り消せない操作がある理由、Reflog を使って失われたコミットを復元する方法を説明します。"
---

Spooky でリポジトリに対して行う操作のほとんどは、<kbd>⌘Z</kbd> で取り消せます。それ以外の場合も、Git の Reflog がブランチのこれまでの位置を記録しているため、コミットが完全に失われることはめったにありません。

## 取り消しとやり直し {#undo}

直前の操作を取り消すには、:ui[menu.edit > menu.undo]（<kbd>⌘Z</kbd>）を選びます。メニュー項目には操作の名前が入ります。もう一度実行するには、:ui[menu.edit > menu.redo]（<kbd>⇧⌘Z</kbd>）を選びます。新しいものから順に、複数の操作をさかのぼって取り消せます。

たとえば、次の操作を取り消せます。

- ステージ、コミット、コミットの修正
- 変更の破棄、ファイルをゴミ箱に入れる操作
- スタッシュの保存、適用、削除
- ブランチのチェックアウト、作成、名前変更、削除、タグの作成
- ブランチのピン留めとアーカイブ、上流の設定、早送り
- マージ、リベース、チェリーピック、リバート、リセット
- リモートの追加、名前変更、削除、リモートの設定の変更
- ブランチとタグの公開、リモートブランチの名前変更
- ファイルの assume-unchanged の設定、Git LFS の有効化、サブモジュールの変更

ゴミ箱に入ったファイルは、ゴミ箱から元の場所に戻されます。追跡中のファイルに変更がある状態でリセットを取り消すと、Spooky は先にそれらをスタッシュするかどうかを尋ねます。新しいスタッシュは一覧に残ります。

コミットメッセージなどのテキストフィールドに入力している間は、<kbd>⌘Z</kbd> は入力を取り消します。

取り消しの履歴はリポジトリごとに 1 つで、そのリポジトリのすべてのウインドウで共有されます。Spooky は終了するまでこの履歴を保持します。必要なスナップショットはリポジトリ自体の Git データベースに保存され、どこにもプッシュされません。

:::note[サーバリポジトリ]
スナップショットは、サーバ上のリポジトリに保存されます。サーバのゴミ箱に入ったファイルは、そこから戻されます。
:::

## 取り消せない操作 {#cant-undo}

取り消しは、リポジトリを元の状態に戻します。一部の変更は、Spooky が復元できる範囲の外にあります。

- リモート上のブランチとタグの削除。ローカルブランチをそのリモートブランチと一緒に削除した場合は例外で、取り消すと両方が作り直されます。
- コミッタの ID、無視ルール、そのほかの Git 設定の変更。
- マージ、リベースなどの操作が進行している間に行ったこと。その操作の続行や中止も含みます。
- 競合で止まったリベースまたはチェリーピック。競合で止まったマージまたはリバートは取り消すことができ、取り消すとその操作が中止されます。
- 完全に削除された新しいファイル。たとえば、ゴミ箱のないサーバ上のファイルです。
- サブモジュールの初期化、同期、修復、ワークツリーに対するすべての操作、Git LFS のフックの更新、ホスティングサービスへのリポジトリの公開。[サブモジュール](/guide/advanced/submodules/#undo)、[ワークツリー](/guide/advanced/worktrees/#undo)、[Git LFS](/guide/advanced/lfs/#undo)、[リポジトリを公開する](/guide/hosting/accounts/#publish) を参照してください。

これらのいずれかを行うと、メニュー項目にはその操作を取り消せないことが表示されます。それより前の操作も取り消せなくなります。

フェッチ、プル、プッシュ、同期は記録されず、取り消せません。サブモジュールのフェッチと更新、LFS コンテンツのフェッチ、プル、プッシュも同じです。

## 取り消しができないとき {#blocked}

取り消しは、リポジトリが操作の直後の状態のままである間だけ使えます。そうでないときは、メニュー項目が淡く表示され、かっこ内に理由が示されます。

| 理由 | 対処 |
|---|---|
| :ui[undo.reason.busy] | 実行中の操作が終わるのを待つか、進行中のマージ、リベースなどの操作を完了します。 |
| :ui[undo.reason.disconnected] | サーバに再接続します。 |
| :ui[undo.reason.changed] | 操作のあとでリポジトリが変更されています。プルや同期でコミットが取り込まれたか、ターミナルやほかのアプリケーションが変更しました。元の状態に戻すと、また取り消せるようになります。 |

Spooky は、取り消しを実行する直前にもう一度リポジトリを確認します。妨げになるものがあれば、中断して理由を知らせます。何も変更されません。

| メッセージ | 理由 |
|---|---|
| :ui[undo.error.changed] | リポジトリが、Spooky が記録した状態と一致しなくなっています。 |
| :ui[undo.error.untracked] | 復元すると、未追跡のファイルが上書きまたは削除されます。 |
| :ui[undo.error.hidden] | assume-unchanged に設定されたファイルにローカルの変更があるか、リポジトリが skip-worktree を使っています。 |
| :ui[undo.error.inProgress] | 先にマージ、リベース、チェリーピック、リバートを完了するか中止します。 |
| :ui[undo.error.conflicts] | 先に競合を解決します。[競合を解決する](/guide/work/conflicts/) を参照してください。 |
| :ui[undo.error.trash] | 一部のファイルがもうゴミ箱にないか、元の場所に別のファイルがあります。 |

## Reflog でコミットを復元する {#reflog}

Git は、HEAD とそれぞれのローカルブランチが指していた場所を記録しています。リセット、リベース、ブランチの削除で失ったコミットは、たいていそこに残っています。一度もコミットしていない変更は残っていません。

1. :ui[menu.view > reflog.show]（<kbd>⌘6</kbd>）を選びます。
2. 上部の :ui[reflog.ref] で、HEAD またはローカルブランチを選びます。
3. 目的のエントリを探します。それぞれのエントリには、短いハッシュ、何が起きたか、その日時が表示され、下に Git の説明が付きます。一覧を絞り込むには、ツールバーの検索フィールドに入力します。
4. エントリを選択すると、コミットの詳細が表示されます。

::screenshot[HEAD の Reflog の表示。それぞれのエントリに、短いハッシュ、commit、checkout、reset などの動作、日付が表示され、その下にメッセージがあります。選択中のエントリのコミットの詳細が右側に表示されています。]{name="work-reflog" frame="window" markers="33.5,9 44.1,37.1 84.4,21.3"}

1. :ui[reflog.ref] メニュー
2. 選択中のエントリ
3. コミットの詳細

エントリを右クリックして、コミットを復元します。

- :ui[reflog.createBranch]{1="9e0d36a7"} は、そこから新しいブランチを始めます。現在のブランチはそのままです。
- :ui[reflog.restore]{1="feature/units-toggle" 2="9e0d36a7"} は、表示しているブランチをそのコミットに戻します。作業コピーとインデックスは変わりません。Spooky は先に確認を求め、この操作は取り消せます。
- :ui[reflog.cherryPick]{1="9e0d36a7"} は、コミットを現在のブランチにコピーします。エントリをサイドバーの :ui[workspace.title] または現在のブランチにドラッグすることもできます。
- :ui[reflog.reset]{1="9e0d36a7"} は、リセットのダイアログを開き、現在のブランチをそのコミットに移動します。
- :ui[patch.menu]{1="9e0d36a7"} は、コミットをパッチファイルとして保存します。

サイドバーに :ui[reflog.title] を表示するには、:ui[sidebar.viewSettings] で :ui[sidebar.showReflog] をオンにします。

:::caution
Git は、古い Reflog のエントリを時間とともに削除します。デフォルトでは、エントリは 90 日間保持され、そのコミットがブランチ上になくなった場合は 30 日間保持されます。失われたコミットは早めに復元してください。
:::

:::note[サーバリポジトリ]
Reflog は、サーバ上のリポジトリにあります。Spooky はそこから読み込みます。
:::

このガイドでは、Spooky で日々の Git 作業を行う方法を説明します。この Mac 上のリポジトリも、別のマシンに置いたまま SSH でアクセスするリポジトリも対象です。各ページは作業の分野ごとに分かれていて、冒頭にそのページでできることを書いています。

Spooky を初めて使うときは、「はじめに」のページを順に読んでください。リポジトリがサーバにある場合は、続けて「サーバリポジトリ」を読んでください。

Spooky で :ui[menu.help > help.help]（<kbd>⌘?</kbd>）を選ぶと、この Web サイトが開きます。多くのダイアログにはヘルプボタンもあり、クリックするとこのガイドの中でそのダイアログを説明している部分が開きます。

## 表記のルール {#conventions}

### 画面上の名前 {#names}

ボタン、メニュー、オプション、ウインドウの名前は、:ui[working.commit] のように太字で書きます。名前は Spooky からそのまま取っています。Spooky をこのページと同じ言語で使っていれば、画面にも同じ名前が表示されます。

:ui[menu.file > action.openLocal] のようなメニューパスは、メニューバーで最初の名前をクリックし、開いたメニューから次の名前を選ぶ、という意味です。

**システム設定** のように、macOS の画面の名前が出てくるページもあります。これらは macOS の表示どおりに書いています。

### キーボードショートカット {#shortcuts}

ショートカットは <kbd>⇧⌘A</kbd> のようにキーキャップの形で書きます。修飾キーを押したまま、最後のキーを押します。記号は macOS のメニューに表示されるものと同じです。

| 記号 | キー |
|---|---|
| <kbd>⌘</kbd> | Command |
| <kbd>⇧</kbd> | Shift |
| <kbd>⌥</kbd> | Option |
| <kbd>⌃</kbd> | Control |
| <kbd>↩</kbd> | Return |
| <kbd>⌫</kbd> | Delete |

すべてのショートカットは [キーボードショートカット](/reference/shortcuts/) にまとめてあります。

### サーバリポジトリについての注記 {#server-notes}

サーバリポジトリは別のマシンに置いたままで、Spooky が SSH 経由で開きます。ほとんどの作業は同じやり方でできます。違いがあるところでは、次のような注記で説明します。

:::note[サーバリポジトリ]
このタイトルの注記には、サーバリポジトリで異なる点を書いています。この Mac 上のリポジトリしか使わない場合は、読み飛ばしてかまいません。
:::

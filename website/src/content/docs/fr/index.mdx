<More>[Fonctionnement des dépôts sur un serveur](/guide/server/overview/)</More>

<Grid columns={4}>

<Point icon="server" title="Aucun clone sur votre Mac">

L’arbre de travail reste sur le serveur. Vous ne le clonez pas d’abord sur votre Mac.

</Point>

<Point icon="terminal" title="Git s’exécute sur le serveur">

Spooky utilise le Git du serveur, et lit et écrit les fichiers via SFTP.

</Point>

<Point icon="key" title="Le SSH que vous utilisez déjà">

Les connexions passent par le SSH du système et les alias d’hôte de `~/.ssh/config`. OpenSSH gère l’authentification, les clés d’hôte et le partage de connexion.

</Point>

<Point icon="script" title="Ni accès root, ni service en arrière-plan">

Spooky n’a pas besoin d’accès root sur le serveur et n’y installe aucun service en arrière-plan. Il y garde seulement un petit script dans `~/.spooky/bin/`.

</Point>

</Grid>

<Feature

Choisissez :ui[action.addRemote], saisissez un alias d’hôte de `~/.ssh/config`, puis tapez le chemin du dépôt sur le serveur ou parcourez le serveur pour le trouver.

Spooky vérifie la connexion et ouvre le dépôt.

</Feature>

<Feature
  title="Branches, synchronisation, fusion et rebasage"
  reverse
  shots={[
    { name: 'branches', alt: 'La section Branches de la barre latérale.', frame: 'closeup' },

Récupérez, tirez et poussez depuis la barre d’outils.

Faites glisser une branche sur la branche actuelle pour la fusionner, ou maintenez <kbd>⌥</kbd> pendant le glissement pour rebaser sur elle.

</Feature>

<Feature
  title="Un assistant pour les conflits"
  reveal
  shots={[
    {

      frame: 'window',
    },
  ]}
>

Pour chaque fichier en conflit, Spooky présente la version de chaque côté.

Choisissez-en une pour résoudre le fichier avec elle, ou sélectionnez les deux et ouvrez un outil de fusion.

</Feature>

<Grid columns={4}>

<Point icon="history" title="Historique et recherche">

Suivez chaque branche dans le graphe des commits. Cherchez par message, auteur, validateur, fichier, hash de commit ou date.

</Point>

<Point icon="undo" title="Annuler et rétablir">

Les commits, les reverts, les remisages et bien d’autres opérations s’annulent avec <kbd>⌘Z</kbd> et se rétablissent avec <kbd>⇧⌘Z</kbd>.

</Point>

<Point icon="pullRequest" title="Pull requests et merge requests">

Listez-les, créez-les, discutez-en, extrayez-les, fusionnez-les et fermez-les sur GitHub, GitLab.com et <mark>GitLab auto-hébergé</mark>.

</Point>

<Point icon="layers" title="Remisages, sous-modules, <mark>worktrees</mark> et Git LFS">

Tout cela fonctionne aussi dans les dépôts sur un serveur.

</Point>

</Grid>

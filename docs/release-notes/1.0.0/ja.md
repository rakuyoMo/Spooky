### 新機能

- ローカルの Git リポジトリを開くほか、別のマシン上のリポジトリを SSH 経由で直接操作できます。~/.ssh/config のホストエイリアスで接続し、作業コピーはサーバ上に置いたまま、接続が切れても自動で再接続します
- 「作業コピー」でファイル、ブロック、行単位でステージ・破棄し、コミットや直前のコミットの修正ができます。破棄・削除したファイルはゴミ箱に入ります
- Diff はシンタックスハイライト、不可視文字の表示、空白の無視、コンテキスト行数の調整に対応し、テキストテーマをカスタマイズできます
- 「履歴」にコミットグラフを表示し、正規表現で検索できます。コミットの詳細、「ファイル履歴」、「Reflog」もあります
- ブランチ、タグ、リモート：フェッチ、プル、プッシュと自動フェッチ。マージ、リベース、チェリーピック、スタッシュに対応し、コンフリクトもアプリ内で解決できます
- 多くの操作を取り消せます
- GitHub と GitLab（セルフホスト版を含む）のアカウントで、プルリクエストとマージリクエストの作成、表示、コメント、チェックアウト、マージができます
- サブモジュール、ワークツリー、Git LFS
- 同じリポジトリへの書き込み操作は順番に 1 つずつ実行され、待機中の操作は取り消せます
- サーバのリポジトリをこの Mac にマウントし、「Finder に表示」で開けます
- 「クイックアクション」、spooky:// リンク、ターミナル、外部の比較・マージツール、Dock メニュー、通知
- 設定の「外観」でアプリアイコンを選べます
- 英語、簡体字中国語、繁体字中国語、日本語、韓国語、ドイツ語、フランス語、スペイン語に対応
- 自動アップデート

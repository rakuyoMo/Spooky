### 새 기능

- 로컬 Git 저장소를 열고, 다른 머신에 있는 저장소도 SSH로 직접 다룰 수 있습니다. ~/.ssh/config의 호스트 별칭으로 연결하고, 작업 사본은 서버에 그대로 두며, 연결이 끊기면 자동으로 다시 연결합니다
- “작업 사본”에서 파일, 블록, 줄 단위로 스테이지하거나 버리고, 커밋하거나 최근 커밋을 수정할 수 있습니다. 버리거나 삭제한 파일은 휴지통으로 이동합니다
- Diff는 구문 강조, 보이지 않는 문자 표시, 공백 무시, 문맥 줄 수 조정을 지원하며, 텍스트 테마를 원하는 대로 바꿀 수 있습니다
- “기록”에 커밋 그래프를 보여 주고 정규 표현식으로 검색할 수 있습니다. 커밋 세부 정보, “파일 기록”, “Reflog”도 있습니다
- 브랜치, 태그, 리모트: 가져오기, 풀, 푸시와 자동 가져오기. 병합, 리베이스, 체리픽, 스태시를 지원하고 충돌도 앱에서 바로 해결합니다
- 많은 작업을 실행 취소할 수 있습니다
- GitHub와 GitLab(자체 호스팅 GitLab 포함) 계정으로 풀 리퀘스트와 머지 리퀘스트를 만들고, 보고, 댓글을 달고, 체크아웃하고, 병합할 수 있습니다
- 하위 모듈, 작업 트리, Git LFS
- 같은 저장소의 쓰기 작업은 대기열에 들어가 하나씩 실행되며, 대기 중인 작업은 취소할 수 있습니다
- 서버 저장소를 이 Mac에 마운트하고 “Finder에서 보기”로 열 수 있습니다
- “빠른 동작”, spooky:// 링크, 터미널, 외부 비교 및 병합 도구, Dock 메뉴, 알림
- 설정의 “모양”에서 앱 아이콘을 선택할 수 있습니다
- 영어, 중국어(간체), 중국어(번체), 일본어, 한국어, 독일어, 프랑스어, 스페인어 지원
- 자동 업데이트

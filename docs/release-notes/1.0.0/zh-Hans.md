### 新增

- 打开本机的 Git 仓库，也可以经 SSH 直接操作另一台机器上的仓库：通过 ~/.ssh/config 里的主机别名连接，工作区留在服务器上，连接断开后自动重连
- 在 “工作区” 按文件、块或行暂存与丢弃改动，再提交或修补最近提交；丢弃和删除的文件移到废纸篓
- Diff 支持语法着色、显示不可见字符、忽略空白与调整上下文，文本主题可以自定义
- “历史” 显示提交图，可以按正则表达式搜索，另有提交详情、“文件历史” 与 “Reflog”
- 分支、标签与远端：获取、拉取与推送，也可以自动获取；合并、变基、摘取与储藏，冲突直接在 App 里解决
- 许多操作可以撤销
- GitHub 与 GitLab 账号，包括私有部署的 GitLab：创建、查看、评论、检出与合并 Pull Request 和 Merge Request
- 子模块、工作树与 Git LFS
- 同一仓库的写操作排队，一次执行一个，还在等待的可以取消
- 服务器仓库可以挂载到这台 Mac，用 “在访达中显示” 打开
- “快捷操作”、spooky:// 链接、终端、外部比较与合并工具、Dock 菜单与系统通知
- 在设置的 “外观” 页选择应用图标
- 支持简体中文、繁体中文、英文、日文、韩文、德文、法文与西班牙文
- 自动更新

### 新增

- 打開本機的 Git 儲存庫，也可以經 SSH 直接操作另一台機器上的儲存庫：透過 ~/.ssh/config 裡的主機別名連線，工作區留在伺服器上，連線中斷後自動重新連線
- 在 “工作區” 按檔案、區塊或行暫存與捨棄改動，再提交或修補最近提交；捨棄和刪除的檔案會丟到垃圾桶
- Diff 支援語法著色、顯示不可見字元、忽略空白與調整上下文，文字主題可以自訂
- “歷史” 顯示提交圖，可以用正規表示式搜尋，另有提交詳情、“檔案歷史” 與 “Reflog”
- 分支、標籤與遠端：擷取、拉取與推送，也可以自動擷取；合併、變基、摘取與儲藏，衝突直接在 App 裡解決
- 許多操作可以還原
- GitHub 與 GitLab 帳號，包括私有部署的 GitLab：建立、檢視、評論、檢出與合併 Pull Request 和 Merge Request
- 子模組、工作樹與 Git LFS
- 同一儲存庫的寫入操作會排隊，一次執行一個，還在等待的可以取消
- 伺服器儲存庫可以掛載到這台 Mac，用 “在 Finder 中顯示” 打開
- “快速操作”、spooky:// 連結、終端機、外部比較與合併工具、Dock 選單與系統通知
- 在設定的 “外觀” 頁選擇 App 圖示
- 支援簡體中文、繁體中文、英文、日文、韓文、德文、法文與西班牙文
- 自動更新

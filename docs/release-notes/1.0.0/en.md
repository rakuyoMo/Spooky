### New

- Open local Git repositories, or work on repositories on another machine over SSH: Spooky connects through a host alias in ~/.ssh/config, keeps the working copy on the server, and reconnects automatically when the connection drops
- In **Working Copy**, stage and discard changes by file, chunk, or line, then commit or amend; discarded and deleted files go to the Trash
- Diffs with syntax highlighting, invisible characters, whitespace options, and adjustable context, plus customizable text themes
- **History** shows a commit graph and supports regular-expression search, alongside commit details, **File History**, and **Reflog**
- Branches, tags, and remotes: fetch, pull, and push, with automatic fetching; merge, rebase, cherry-pick, and stash, and resolve conflicts right in the app
- Undo for many operations
- GitHub and GitLab accounts, including self-hosted GitLab: create, review, comment on, check out, and merge pull requests and merge requests
- Submodules, worktrees, and Git LFS
- Write operations on the same repository wait in a queue and run one at a time; waiting operations can be cancelled
- Mount a server repository on this Mac and open it with **Show in Finder**
- **Quick Actions**, spooky:// links, terminals, external diff and merge tools, a Dock menu, and notifications
- Choose an app icon on the **Appearance** settings page
- Available in English, Simplified Chinese, Traditional Chinese, Japanese, Korean, German, French, and Spanish
- Automatic updates

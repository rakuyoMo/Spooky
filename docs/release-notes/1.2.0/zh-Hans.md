### 新增

- 仓库窗口窄到放不下三栏时，会换成窄窗口的版式：侧边栏换成工具栏下面的一行，用来切换 “工作区”、“历史” 与 “储藏”，列表与详情上下排列；点这一行开头的 “侧边栏” 按钮，完整的侧边栏会盖在视图上面。把窗口拉宽，三栏回到原来的宽度，所在的视图、选中的内容与正在写的提交信息都不变
- 窄窗口里，工具栏上放不下的按钮收进 » 菜单，“获取”、“拉取” 与 “推送” 一直留在工具栏上
- “仓库管理” 窗口变窄时也会换版式：仓库列表在上，所选仓库的详情在下，可以拖动两者之间的分隔线
- 想固定用一种版式，在 “视图” 菜单的 “窗口版式” 里选 “窄版” 或 “宽版”，窗口不论宽窄都用这种版式；默认的 “自动” 跟着窗口的宽度换版式。这个选择对所有窗口生效
- “仓库管理” 里可以直接更改仓库的位置，不用删掉再重新添加：在详情里把指针移到 “位置” 一行，点 “编辑”；服务器仓库可以只改主机别名或只改路径。仓库所在的分组与你改过的名称都不变
- 请求详情的 “CI/CD” 视图里，有日志的检查或作业可以展开，日志显示在这一行下面：GitHub Actions 的作业结束后有日志；GitLab 流水线里的每个作业都能展开，作业还在运行时，日志跟着状态一起更新
- 请求的标签可以在 “讨论” 里添加与移除：点标签名称后面的 × 移除它，点 “添加” 从项目的标签里选一个，也可以用 “新建标签…” 新建一个并加到请求上
- 写请求的评论、回复或编辑评论时，输入 @ 可以提及某个人：Spooky 列出参与这个请求的人和项目的成员，随着你继续输入用户名或名字缩小范围，按 Return 键插入用户名

### 改进

- Pull Request 与 Merge Request 列表改用标题前的图标表示状态，取代标题后面的文字：打开着的请求是绿色，草稿是灰色，已关闭是红色，已合并是紫色
- 设置的 “更新” 页里，更新通道改叫 “稳定版”、“公测版” 与 “内测版”；公测版与内测版的版本号带上 beta 或 alpha 标记，如 1.2.0-beta.1，在 “关于 Spooky” 与更新窗口里一眼就能认出

### 修复

- 每次更新 Spooky 后，读取账号的令牌与钥匙串里保存的凭据时不再要求输入钥匙串密码；安装这一版后，已保存的每一项第一次读取时还会询问一次
- 在设置的 “SSH 主机” 页修改别名后，书签里这台主机上的仓库不再按旧别名连接而失败；这些仓库的各项设置与钥匙串里保存的凭据也一起换到新别名
- 查看 Pull Request 或 Merge Request 时，“刷新” 与 ⌘R 会重新读取列表与所选的请求；在同一个窗口里回到这个仓库时，列表也会重新读取
- 重新读取 Pull Request 或 Merge Request 列表时，选中的请求排在后面也不再被取消选中，详情也留着
- 设置的 “通用” 页关着 “在仓库管理中列出工作树” 时，打开工作树不再自动为它添加书签

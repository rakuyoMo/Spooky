### 新增

- 儲存庫視窗窄到放不下三欄時，會換成窄視窗的版面：側邊欄換成工具列下面的一列，用來切換 “工作區”、“歷史” 與 “儲藏”，列表與詳細資訊上下排列；按一下這一列開頭的 “側邊欄” 按鈕，完整的側邊欄會蓋在視圖上面。把視窗拉寬，三欄回到原來的寬度，所在的視圖、選取的內容與正在寫的提交訊息都不變
- 窄視窗裡，工具列上放不下的按鈕收進 » 選單，“擷取”、“拉取” 與 “推送” 一直留在工具列上
- 請求詳情的 “CI/CD” 視圖裡，有記錄的檢查或工作可以展開，記錄顯示在這一列下面：GitHub Actions 的工作結束後有記錄；GitLab 流水線裡的每個工作都能展開，工作還在執行時，記錄跟著狀態一起更新
- 請求的標籤可以在 “討論” 裡加入與移除：按一下標籤名稱後面的 × 移除它，按一下 “加入” 從專案的標籤裡選一個，也可以用 “新增標籤…” 新增一個並加到請求上

### 改進

- Pull Request 與 Merge Request 列表改用標題前的圖示表示狀態，取代標題後面的文字：開啟著的請求是綠色，草稿是灰色，已關閉是紅色，已合併是紫色
- 設定的 “更新” 頁裡，更新頻道改叫 “穩定版”、“公測版” 與 “內測版”；公測版與內測版的版本號碼帶上 beta 或 alpha 標記，如 1.2.0-beta.1，在 “關於 Spooky” 與更新視窗裡一眼就能認出

### 修正

- 每次更新 Spooky 後，讀取帳號的權杖與鑰匙圈裡儲存的登入憑證時不再要求輸入鑰匙圈密碼；安裝這一版後，已儲存的每一項第一次讀取時還會詢問一次
- 在設定的 “SSH 主機” 頁修改別名後，書籤裡這台主機上的儲存庫不再以舊別名連線而失敗；這些儲存庫的各項設定與鑰匙圈裡儲存的登入憑證也一起換到新別名

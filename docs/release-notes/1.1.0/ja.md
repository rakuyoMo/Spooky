### 新機能

- 設定に「SSH ホスト」ページを追加しました。~/.ssh/config のホストエイリアスを表示、追加、編集、削除できます。エイリアスをダブルクリックするか Return を押すと編集でき、Spooky は編集した行だけを書き換えるので、ほかのオプションやコメントはそのまま残ります
- プルリクエストとマージリクエストの一覧を「オープン」から「すべて」に切り替えると、クローズ済みとマージ済みのリクエストも表示されます
- リクエストのラベルを一覧と「会話」に表示します
- リクエストの詳細に「CI/CD」表示を追加しました。全体の状態と、チェックやジョブごとの結果を表示し、待機中や実行中のものがあるあいだは自動で更新します。一覧の各行にも CI/CD の状態を表示します

### 改善

- サーバのリポジトリで、接続、Git コマンド、ファイルの読み書き、取り消しが速くなりました。遅延の大きいネットワークほど効果が大きく、接続が切れたこともすぐに検知します
- 「コミットの件名」に複数行のテキストをペーストすると、1 行目は件名に残り、残りは「詳細な説明」に入ります
- 「リポジトリ」ウインドウで Return を押すと、リポジトリを開く代わりに、選択したブックマークやグループの名前を変更するようになりました。Esc で取り消せます。リポジトリはダブルクリックで開きます。選択中の行の名前をクリックしても、名前の変更は始まりません
- リポジトリウインドウのデフォルトのツールバーに「Finder」、「ターミナル」、「強制プッシュ」、「ブランチを作成」が加わり、「クイックアクション」、「同期」、「マージ」、「リベース」は必要に応じて「ツールバーをカスタマイズ…」から追加する形になりました。新しい配置にすべて切り替えるには、そこでデフォルトのセットをツールバーにドラッグします
- ブックマークを削除するとき、フォルダがすでにサーバにないリポジトリでは、ゴミ箱のチェックボックスは選択できず、ブックマークだけが取り除かれます
- GitLab のリポジトリを開き直すと、リモートを読み込む前から「マージリクエスト」と表示します
- GitLab は、マージリクエストのクローズまたはマージから 14 日後にソースブランチの参照を削除します。そのあとでコミットを取得しようとすると「コミットを取得できなくなりました」と表示します
- ブランチの切り替えやステージなどの操作が、git-lfs が見つからずに失敗したとき、エラーのタイトルが「Git LFS を使用できません」になり、ローカルとサーバのリポジトリそれぞれについて PATH の設定方法を案内します
- サーバの ~/.spooky/bin にある古いバージョンのヘルパースクリプトは、30 日間使われないと自動で削除されます
- すべての言語で、画面の用語と句読点をそろえました

### 修正

- サーバのリポジトリでファイルを書き込む途中で接続が切れたり書き込みを取り消したりしても、元のファイルが壊れなくなりました
- ネットワークが一時的に止まっても、サーバのリポジトリの接続と実行中のコマンドが中断されなくなりました
- サーバのリポジトリでファイルの書き込みを取り消したあと、接続済みと表示されているのに次の書き込みが拒否されることがなくなりました
- サーバのリポジトリで Git が新しく作るファイルのアクセス権が、ログイン時の umask に従うようになりました。SSH でログインして Git を実行したときと同じです
- リモートの URL に含まれるパスワードが、アクティビティのログやエラーメッセージに表示されなくなりました
- パスは同じに見えてもバイト列が異なる 2 つのサーバのリポジトリが、1 つの接続を共有しなくなりました
- アプリアイコンを続けて変更したとき、最後に選んだグループが反映されるようになりました
- ツールバーの「クローン」を移動したり取り除いたりできるようになり、「ツールバーをカスタマイズ…」にも常に表示されます
- プルのとき、アクティビティの概要に Git のフェッチ結果がそのまま表示されなくなりました

### 新增

- 设置新增 “SSH 主机” 页，可以查看、添加、编辑与删除 ~/.ssh/config 里的主机别名，连按别名或按 Return 键即可编辑；Spooky 只改你动过的那几行，其它选项与注释保持原样
- Pull Request 与 Merge Request 列表可以从 “打开着的” 切换到 “全部”，连已关闭与已合并的请求一起列出
- 请求的标签显示在列表与 “讨论” 里
- 请求详情新增 “CI/CD” 视图，显示整体状态与每一项检查或作业的结果，等待或运行中时自动刷新；列表的每一行也显示 CI/CD 状态

### 改进

- 服务器仓库的连接、Git 命令、文件读写与取消都更快，网络延迟高时尤其明显；连接断开时也能更快察觉
- 在 “提交标题” 里粘贴多行文字时，第一行留在标题，其余内容放进 “详细说明”
- 在 “仓库管理” 窗口里，按 Return 键改为重命名选中的书签或分组，不再打开仓库，按 Esc 取消；打开仓库用连按，点按已选中行的名称也不再进入重命名
- 仓库窗口的默认工具栏加入 “访达”、“终端”、“安全强推” 与 “新建分支”，“快捷操作”、“同步” 与 “合并” “变基” 改为按需从 “自定工具栏…” 加入；想完整换成新的排布，在那里把默认的一组拖到工具栏上
- 删除书签时，如果服务器上已经没有这个仓库的文件夹，移到废纸篓的复选框是灰的，只移除书签
- 再次打开 GitLab 仓库时，一开始就按 Merge Request 称呼请求，不用等读出远端
- Merge Request 关闭或合并满 14 天后，GitLab 会删掉它的源分支引用；这时取回它的提交会提示 “提交已无法取回”
- 切换分支、暂存等操作因为找不到 git-lfs 而失败时，错误提示为 “Git LFS 不可用”，并按本机或服务器仓库说明怎样设置 PATH
- 服务器上 ~/.spooky/bin 里超过 30 天没有用过的旧版辅助脚本会自动删除
- 各语言界面文字的用词与标点更统一

### 修复

- 在服务器仓库里写文件时中途断线或取消，不再损坏原文件
- 网络短暂停顿时，服务器仓库的连接与正在执行的命令不再中断
- 取消服务器仓库的文件写入后，不再显示已连接、之后的写入却被拒绝
- 服务器仓库里 Git 新建的文件按登录时的 umask 设置权限，与直接登录服务器执行 Git 时相同
- 远端地址里带的密码不再出现在活动日志与错误信息里
- 路径看起来相同、字节不同的两个服务器仓库不再共用一条连接
- 连续更换应用图标时，最后选的那一组生效
- 工具栏的 “克隆” 项可以移动和移除，“自定工具栏…” 里也一直列出它
- 拉取时，活动的摘要不再显示 Git 写出的原始获取结果

# M22 菜单、侧边栏、工作区、Diff、提交、历史、分支与设置的验收

范围：主菜单的系统项与可用条件、工具栏自定义面板、对话框底栏与输入列、索引被锁的说明、仓库被移走后的窗口、仓库管理、克隆与快捷操作；侧边栏的外观、右键菜单、双击、删除键、过滤与拖放，Branches Review；Working Copy 的状态头、排序、未跟踪目录、树形、文件菜单、冲突文件、搜索与文件对话框；文件详情头部、Diff 底栏与 Diff 区、图片 Diff、Blame 与原文；提交区、补全、操作横幅、空提交确认、冲突向导与储藏；历史列表、搜索、提交详情、整页详情、Reflog 与文件历史；分支、标签、远端、父分支、检出、同步、改写与撤销；设置窗口、仓库设置与详情页、子模块与工作树、托管与系统通知。M1–M21 的验收步骤继续适用。

## 准备

按 [M7](M7.md) 的 “准备测试仓库” 与 [M21](M21.md) 的 “准备” 建好 `history`、`refs`、`rewrite`、`modules` 与 `wc`，沿用 `m7_root`、`m7_git`、`m21_root`、`m21_git`。另建冲突与图片用的仓库：

```sh
m22_root="$(mktemp -d "${TMPDIR:-/tmp}/spooky-m22.XXXXXX")"
m22_git() { "$m7_root/git" -C "$m22_root/$1" "${@:2}"; }

# conflicts：AA、UU、UD、DU 四种冲突各一个文件
"$m7_root/git" -c init.templateDir= init -q -b main "$m22_root/conflicts"
m22_git conflicts config --local user.name 'Spooky Test'
m22_git conflicts config --local user.email spooky@example.invalid
m22_git conflicts config --local commit.gpgSign false

printf 'base\n' | tee "$m22_root/conflicts/uu.txt" "$m22_root/conflicts/ud.txt" > "$m22_root/conflicts/du.txt"
m22_git conflicts add --all
m22_git conflicts commit -q -m 'Base'

m22_git conflicts switch -q -c other
printf 'other\n' | tee "$m22_root/conflicts/aa.txt" "$m22_root/conflicts/uu.txt" > "$m22_root/conflicts/du.txt"
m22_git conflicts rm -q ud.txt
m22_git conflicts add --all
m22_git conflicts commit -q -m 'Change on other'

m22_git conflicts switch -q main
printf 'main\n' | tee "$m22_root/conflicts/aa.txt" "$m22_root/conflicts/uu.txt" > "$m22_root/conflicts/ud.txt"
m22_git conflicts rm -q du.txt
m22_git conflicts add --all
m22_git conflicts commit -q -m 'Change on main'

# images：同一张 PNG 改尺寸后的两版
"$m7_root/git" -c init.templateDir= init -q -b main "$m22_root/images"
m22_git images config --local user.name 'Spooky Test'
m22_git images config --local user.email spooky@example.invalid
sips -s format png -z 96 96 /System/Library/CoreServices/Finder.app/Contents/Resources/Finder.icns --out "$m22_root/images/icon.png" > /dev/null
m22_git images add icon.png
m22_git images commit -q -m 'Add the icon'
sips -z 128 128 "$m22_root/images/icon.png" > /dev/null

# wc：一个只有未跟踪文件的目录
mkdir -p "$m21_root/wc/new dir/sub"
printf 'a\n' > "$m21_root/wc/new dir/a.txt"
printf 'b\n' > "$m21_root/wc/new dir/sub/b.txt"

./scripts/build-app.sh
open -n -a .build/Spooky.app "$m21_root/wc"
```

冲突在用到时执行 `m22_git conflicts merge other`，测完 `m22_git conflicts merge --abort`。

## 窗口、菜单、工具栏与仓库管理

1. 主菜单：Quit Spooky ⌘Q 按住 ⌥ 换成 Quit and Close All Windows ⌥⌘Q，File › Close ⌘W 换成 Close All ⌥⌘W；Edit 菜单 Speech 之后是分隔线、AutoFill、Start Dictation… 与 Emoji & Symbols，Find 与 Spelling and Grammar 之间有分隔线；View 菜单最上面是 Show Tab Bar、Show All Tabs，末尾是系统的 Enter Full Screen；Window 菜单有标签页的四项，没有标签页时前三项不可用。
2. View › Working Copy Status：当前显示方式那一项打勾且不可用，状态头视图设置菜单里的同名两项相同；换到 Pull Requests 视图后 View › History 子菜单仍可用，在那里改了 Show Graph，回到 History 生效。
3. 工具栏 › Customize Toolbar…：后退 / 前进组按段写 Prev、Next，储藏组写 Apply Stash、Save Stash，Apply 的箭头向下、Save 的向上；可选项的顺序是 …、Refresh、Search、Create Branch、Show in Finder、Open in Terminal、Force Push、Push To 与三种空白。VoiceOver 逐段读工具栏的分段，读出段名而不是符号名。
4. 把窗口缩到最窄：Pull Requests 列表能缩到 50，Reflog 与 Branches Review 的列表没有最小宽，History、Stashes 与文件历史的最小宽不变。抽查 Rename Branch、Add Remote 与 Edit Connection Settings：标签右对齐、输入框从距左 145 处开始，头部的标题与说明的左缘与输入框对齐；只有一个短按钮的底栏，按钮不窄于 70。
5. 在 `wc` 里 `touch "$m21_root/wc/.git/index.lock"` 后暂存一个文件：错误框标题 Git Index Locked by Another Git Process，说明是一句删掉 `.git/index.lock` 的提示，下面仍是原文区；测完删掉这个文件。把打开着的仓库目录改名：窗口换成丢失页，只出现一次，改回原名后自动恢复。
6. 仓库管理：随 “系统设置 › 外观 › 侧边栏图标大小” 的小、中、大，书签行高 24、28、32；空选择页的虚线拖放框；书签右键菜单写 Open “<名字>”、Delete “<名字>”…，多选时写计数；详情页的头部图标、分组、行序与日期，本机与服务器书签各看一次；File › Open… 的面板主按钮是 Open Repository；扫描对话框的主按钮固定写 Add Repositories；多选页只有一行 “<n> items selected” 与 Delete。删掉一个书签的仓库目录后右键：Show in Finder 与 Open in Terminal 不可用，Delete 直接删除、不询问。
7. 克隆：在仓库管理与仓库窗口里各发起一次，都是独立的模态窗口，标题为空、只有关闭按钮可用。地址填 `foo`：Clone 不可用、错误区不写字；填一个不存在的仓库地址点 Clone：连接检查失败，对话框不关，失败页标题写克隆失败，没有新目录与书签。
8. 快捷操作：输入为空时列出导航项、本地分支、远端、身份档案、外观与主题，不列远端分支与标签；VoiceOver 读出各项的图标描述。

## 侧边栏、拖放与 Branches Review

1. 浅色与深色各看一次：列表可滚动、Activity 区没有显示时底栏上方有 1 pt 分隔线；本地分支、远端分支、子模块与工作树的图标在窗口活跃时用强调色，不活跃时变灰；在另一个工作树签出的分支图标带小角标，右键首行是不可点的 Checked Out in Worktree “<名字>”；远端行的提示是 Remote repository “origin” 与两行 Fetch URL、Push URL。
2. 右键菜单：HEAD 分支与其它本地分支各看一次分组顺序，复制项写 Copy Branch Name to Clipboard；没有上游时 Force Push with Lease… 不可用；Track Upstream Branch 子菜单两组按公共顺序、当前上游打勾且不可用；选中两个分支时有 Compare “A” with “B”…；先选中 Workspace 行再右键一个分支，菜单只作用于被点的分支。
3. 双击分支、远端分支与标签行（含名字右边的空白）；单独按 ⌫ 不删除，⌘⌫ 弹出删除对话框；跟踪的远端分支已不存在时，删除对话框没有 Delete Tracked Branch。
4. 过滤：输入文字后只保留有匹配分支的远端；按 Esc 只清空文字，过滤框仍展开、仍在编辑；展开后是灰色胶囊，有文字时右端有清除按钮。
5. 拖放：操作标签贴在拖动图像左侧；标签拖到远端上写 Publish；拖动中停在收起的文件夹或远端上约 1 秒，它展开，放下或取消后再收起；文件夹里的分支拖到列表上下边缘，操作标签写 Move Here，放下后移到顶层、不弹确认，⌘Z 可以撤销。
6. Branches Review：超前 / 落后靠右、斜向箭头；上游已不存在时远端分支名与图标为红色；基准菜单顶部是过滤框；Filter 与视图设置菜单的灰色标题与分组；第一次进入时选中第一行；列表有焦点时 ⌘⌫ 弹出 Delete Branch；窄宽度下表头先截断基准名；VoiceOver 读一行，超前 / 落后只读一遍，单数写 “1 commit behind”。

## 工作区

打开 `wc`。

1. 状态头：分支名到 “›”、“›” 到跟踪名的空隙约 5，视图设置按钮平时与悬停时都没有底，提示 Change viewing options。文件图标按实际文件取，`.gitignore` 是文本图标。
2. 列表：按状态排序时已暂存在前、未暂存其次、未跟踪最后；`new dir/` 只占一行，带文件夹图标与 “?”；树形下重命名行写两段完整路径，目录行在有改动的一列显示 “M”。
3. 右键：已删除文件的 Show in Finder 与 Open in Terminal 不可用；多选时 Show 三项指向第一个文件，Ignore ▸ 只有 Ignore N Items 可用；树形的目录行在 Ignore / Exclude 与 Create Ignore Pattern… 里算一项，Pattern 预填这个目录；被忽略文件的 Ignore ▸ 与 Exclude ▸ 都可用。Open With 列出全部能打开该文件的程序。
4. Move…：本机仓库弹出系统保存面板，Where 是文件所在的文件夹；服务器仓库仍是现有的对话框。Create Ignore Pattern… 的 Pattern 不带开头的 “/”。Apply Patch… 的补丁文件一行是弹出按钮，没选文件时写 No Patch File Selected。
5. 搜索框：占位 Search for File，范围菜单与建议列表；树形下输入文字按平铺显示完整路径，没有匹配时只剩表头。
6. 冲突：执行 `m22_git conflicts merge other` 后打开 `conflicts`，四个文件右键都能 Open、Open With 与 Quick Look，Revert to Revision… 可用，Move… 不可用；`ud.txt`、`du.txt` 的 Open Merge Tool 不可用。

## Diff 与文本

1. 头部：动作条隐藏时文件名完整显示，窄宽度下才在中间截断。底栏：Context: 是 11 pt 次级色，后面是无边框的 “7 lines” 弹出按钮；忽略空白开关是禁止符号，两个开关打开时铺强调色圆角底、图标变白；显示整个文件时 Context 仍可用。
2. Diff 区：块头放不下时直接切掉；鼠标单击、⇧ 单击与拖选行号后不画焦点框，键盘移动时画；改动段的描边与底色；文件摘要行与块头同色，正文以下是表格底色。丢弃一整块的确认说明不写 “lines”，也不写不能撤销。
3. 图片：打开 `images`，选中 `icon.png`：图片区铺表格底色、两张图竖直居中，按像素数显示，尺寸说明在图下方；Two-Up / One-Up 与 Old / New 是两组常规尺寸的分段控件，切到 One-Up 时默认 Old。浅色与深色各看一次。
4. Blame 与原文：从工作区头部的动作条与历史变更集的右键菜单分别打开，侧边栏都选中 History；Blame 的栏序是行号、正文、注释栏，注释第一行有圆形头像与相对日期，原文与 Blame 的行高不同；单击注释，popover 贴着被点的那一组弹出；版本与文件选择器的 popover 各打开一次，文件选择器打开时列表为空；正文右键菜单没有 Font 子菜单。

## 提交区、冲突与储藏

1. 提交区：点标题框任何位置都把焦点交给标题；标题框与正文框的焦点环；正文框按 Tab 到文件列表，文件列表按 ⇧Tab 回到正文；钉住按钮的提示 Keep Body View Expanded；勾上 Amend 后姓名与邮箱完整显示，没有悬停提示。
2. 补全：正文里输入 `\` 只列已暂存的文件，行高 22；选中后补一个空格；标题里打 `fixup!` 弹出最近的提交；`c:` 的弹窗位置与 44 pt 的提交行。
3. 横幅与确认：合并、变基与摘取停下时的横幅图标与提示完整显示；合并没有改动时询问空提交，是系统提示框，勾上不再询问后下次不再询问。
4. 冲突向导：执行 `m22_git conflicts merge other`，在窄窗口里打开 `uu.txt` 的向导：右栏约 452 宽，离开后分栏复原；卡片分标题栏、版本摘要与提交栏三段，48 pt 的方形首字母头像，实心色块的改动徽标，两条空心弯箭头指向结果框；单击卡片切换选中，两张都选时结果为两边都用；`ud.txt`、`du.txt` 打开时保持未选；手动编辑工作区文件后结果框带 EDITED 徽标与修改时间；版本菜单写 Compare to Version from “<另一侧>” 与 Compare to Ancestor Version。合并工具选择框先是 None selected，再按名称排列。
5. 储藏：进入 Stashes 视图就选中第一个；列表行不带 “On <分支>: ” 前缀；没有选中写 No stashes selected，多选写 “2 stashes selected”；⌫ 不删除、⌘⌫ 删除；储藏详情用提交详情的版式与文件行；Save Stash 的说明框高 47。说明留空时自动储藏的说明是 “Spooky Auto-Stash: <时间>”。

## 历史、Reflog 与提交详情

打开 `history` 与 `refs`。

1. 列表头：22 × 22 的比较按钮，分支名后的空隙与状态头相同，视图设置按钮无底；关掉 Show Graph 后两个行高项不可用、勾打在 Medium 上，再打开后回到保存的行高。
2. 提交行：中号行空间不够时先把引用徽标折成 “…”，没有箭头的行日期仍在同一列；列表没有焦点时选中行的文字不换色；日期分组标题、小号行与无图布局；VoiceOver 读签名标签的徽标读出标签名。
3. 选择：HEAD 所在提交的 Check Out 与 Reset HEAD to… 不可用；改写的提交里有已推送的，Edit Commit Message 与 Delete 先弹警告；在两个历史范围之间来回切换，各自回到上次的选中与滚动位置。
4. 搜索：范围菜单的 History 组下有 Since Date 与 Until Date；Message 范围下输入文字弹出分组建议；搜索面板的条件行是 header 材质的底。
5. 详情：标签列按最长的 Committer Date 留足；变更集的摘要行与文件行与头部同一内边距；HEAD 分支、其它分支与 Reflog 里的操作条按钮不同；Refs 一行能排出 HEAD、main、v2.0 与 “…”；变更文件按路径不分大小写排序，多选文件的菜单没有两项复制路径。
6. 整页详情：打开即选中第一个文件，窗口副标题写 “Commit <8 位短哈希>”，返回后恢复；工具条上的短哈希是等宽字；首字母头像有 1 pt 描边；版本选择器按日期排序；窄栏里版本比较的头部截断显示。储藏详情与 Branches Review 的变更集摘要行同样核对。
7. Reflog：行高 69，Ref: 后面是无边框的弹出按钮；只有看 HEAD 所在分支时 Reset HEAD to… 可用。文件历史：月份标题行 30、提交行 39，侧边栏保持选中 History。

## 分支、标签、远端、同步与改写

打开 `refs`。

1. 版本候选：新建分支、Create New Tag、Check Out Revision、Track Remote Branch、Set Parent Branch 的候选按公共顺序；没有上游时 Pull 与 Publish Branch 的远端 `origin` 在前并默认选中。名称与已有分支的文件夹同名时报错、主按钮不可用；Add Remote 的名称 `a b` 规范化为 `a-b`。
2. 父分支：Set Parent Branch 对话框宽 486；设了父分支的分支右键有 Update “X”…，按住 ⌥ 换成 Quick Update；Update Branch 对话框与父分支横幅。已有父分支时移除项写 Untrack Parent Branch。
3. 检出：工作区有已跟踪文件的修改时，每次检出都先询问储藏；分离 HEAD 时副标题带短哈希与 “(detached)”。Publish Tag 默认选最后一个标签与 `origin`。
4. Add Remote 与 Edit Connection Settings 填一个连不上的地址：执行期间表单保持打开并显示进度，失败后表单内容保留。
5. 改写：Edit Commit Message 的标题框右端有剩余字数、正文有占位；Squash 的确认；Squash 与 Edit Commit Message 之后选中改写后的提交。Reset 对话框每次打开默认 Soft。
6. 撤销：跟踪远端分支并检出后，⌘Z 先撤销检出、再撤销跟踪；多选删除只删掉一部分时 Cancel 后 Edit 菜单是按删掉的个数命名的撤销；连同远端分支删除后 Undo Delete Branch 推送重建远端分支，远端已变时说明原因；Merge 停在冲突时 Undo Merge 等于 Abort，Redo 再执行一次；Fetch、Pull、Push 与 Sync 之后 Edit 菜单仍是更早的撤销项；撤销 Reset 时有已跟踪修改，先问储藏，三个按钮各试一次；撤销与重做 Rename Remote 后选中跟着远端名走。
7. 本机与服务器仓库各走一遍删除分支、跟踪、合并冲突与撤销。

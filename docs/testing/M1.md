# M1 App 验收

所有命令在仓库根目录执行。界面验收需要已解锁、显示器正常显示的 macOS 会话。

## 自动验证

```sh
swift build --package-path SpookyKit
swift test --package-path SpookyKit
swift build --package-path SpookyKit --product Spooky
./scripts/build-app.sh
```

单元测试覆盖工作区根目录识别、空仓库、未出生分支、分离 HEAD、无上游、领先 / 落后数量、SHA-1 / SHA-256、特殊路径、输出解析错误、命令失败、进程取消、刷新恢复和五种语言资源。

## 准备临时仓库

```sh
m1_directory="$(mktemp -d "${TMPDIR:-/tmp}/spooky-m1.XXXXXX")"
mkdir -p "$m1_directory/仓库 with spaces" "$m1_directory/not-a-repository"

env GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1 \
    /usr/bin/git -C "$m1_directory/仓库 with spaces" \
    -c init.templateDir= init -q -b main

printf 'first file\n' > "$m1_directory/仓库 with spaces/你好 [draft].txt"
printf '%s\n' "$m1_directory"
```

## 启动、打开与刷新

1. 执行 `swift run --package-path SpookyKit Spooky`。确认出现仓库管理空状态，未自动打开 shell 当前目录，截图保存启动界面。
2. 按 ⌘O，使用系统目录选择器打开上面创建的工作区。确认当前窗口变为侧边栏、列表和详情三栏。
3. 确认窗口标题含仓库名与绝对路径；分支为 `main` 且提示尚无提交；上游为空，领先 / 落后均为 0；文件显示 `?` 状态。
4. 选中文件，确认详情显示原始路径与新增文件 Diff。截图保存仓库窗口。
5. 在测试目录新增另一个文件，按 ⌘R，确认列表更新。再新增一个文件并点击工具栏刷新，确认同样更新，仍存在的选中条目保持选中。
6. 按 ⌘2 查看历史，再按 ⌘1 返回工作区。确认菜单只显示已交付功能的操作入口；工作区写操作按 [M3](M3.md) 验收，历史、分支与同步按 [M4](M4.md) 验收。
7. 点击工具栏 “关闭当前仓库”。确认回到管理界面，窗口和 App 进程仍然存在，最近记录保留。

## 窗口复用与最近记录

1. 重新打开临时仓库，再按 ⌘N 新建管理窗口。
2. 在新窗口通过 ⌘O、最近菜单或最近列表双击打开同一仓库。确认激活原仓库窗口，窗口数量不增加，原视图与选区保留。
3. 在管理界面选中记录，点击或右键选择 “在新窗口打开”。确认创建独立窗口；将系统标签页偏好设为 “始终” 后结果相同。
4. 退出并重启 App。确认最近记录仍在，可再次选择打开。
5. 关闭仓库，将测试目录改名，再回到管理界面。确认记录显示不可用，仍可点击重试，失败 sheet 包含 Git 原文并可重新选择目录。
6. 恢复目录原名，再次打开或返回管理界面检查，确认恢复可用状态。
7. 从 Finder 将临时仓库目录拖入管理界面，确认验证后加入列表；非 Git 目录应显示错误。

## 错误与恢复

1. 通过 ⌘O 选择 `not-a-repository`，确认错误标题表明不是 Git 仓库，说明中包含最低版本 `2.41.0` 与 Xcode / 命令行工具更新方向，原始 stderr 可滚动、复制。
2. 重新选择正确工作区，确认可以打开。
3. 打开工作区后把测试目录改名，按 ⌘R。确认旧列表保留，显示错误；恢复原名后重试，确认刷新成功。
4. 快速切换仓库或关闭仓库，确认旧读取结果不会覆盖新窗口状态。

## 语言与外观

1. 生成并打开 `SpookyKit/.build/Spooky.app`，在系统设置中依次将该 App 的语言设为 `en`、`zh-Hans`、`zh-Hant`、`ja`、`ko`，每次退出并重启。
2. 每种语言重复查看启动空状态、仓库窗口和非 Git 目录错误 sheet，并分别截图。确认译文对应所选语言，没有资源键泄漏；Git 原文保持原样。
3. 移除 App 单独语言设置，检查跟随系统语言；在其它系统语言下检查英文回退。
4. 切换系统浅色 / 深色外观，确认窗口、分栏、文字和状态徽标可读。调整窗口大小，确认侧边栏不能折叠、列表与详情仍可使用。

进程语言偏好也可以用于快速复查，不修改系统设置：

```sh
swift run --package-path SpookyKit Spooky -AppleLanguages '(ja)'
```

资源完整性测试不能替代上述界面语言切换。窗口无法操作、屏幕锁定或截图失败时，应将对应项记为未验证。

## 清理

退出本次启动的 Spooky，在保存必要截图后删除本段创建的临时目录：

```sh
rm -rf -- "$m1_directory"
```

最近记录会保留失效路径，这也是 M1 的验收行为。

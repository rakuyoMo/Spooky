# M14：菜单、工具栏、窗口与对话框的对齐验收

M14 承接 [M13](M13.md)，修正前面各里程碑交付的主菜单、工具栏与窗口，M1–M13 的验收步骤继续适用：

- 应用菜单有系统的 Services；Edit 菜单有系统的文本项与五个子菜单；工作区文件列表、书签列表与文本框里按 ⌘⌫ 的行为不变，储藏列表里按 ⌘⌫ 询问删除所选储藏
- File › Open Recent 写仓库文件夹的名字，同名的带上一级文件夹名，末尾的 Clear Menu 清空列表而书签都在
- Repository、Working Copy、View 与 Window 菜单的标题、分组、分隔线与快捷键；⌃⌘U 只属于 Force Push with Lease…
- 窗口显示仓库管理时不能切换主视图，后退照常可用；Diffs in Changeset 的阈值上方有一行标题
- 工具栏：仓库管理入口叫 Bookmarks，后退 / 前进叫 Prev / Next，储藏两段叫 Apply / Save；各项的提示在显示文字与只显示图标两种模式下、按住 ⌥ 前后都对，服务器仓库的主机前缀排在最前
- 窗口变窄时搜索框、Parent Repository、Bookmarks、Create Branch 与 Force Push 最后才进溢出菜单；Fetch 与 Clone 的图标不同，Activity 里获取的记录用 Fetch 的图标
- 只显示图标时，有内层分栏的视图在工具栏上有一条跟随内层分隔线的分隔符；刷新进行中 Refresh 与 ⌘R 照常可用
- 丢失页出现时与窗口每次成为主窗口时都重新读取仓库，仓库回来了就换回仓库界面；服务器仓库重试时不询问凭据
- File › Open… 的目录面板是单独的模态面板，确定按钮写 Open Repository；选了不是仓库的文件夹时以单独的模态对话框询问是否新建
- 还没有记下侧边栏宽度时，仓库视图的侧边栏宽 428 pt；“打开文稿时首选标签页” 为 “始终” 时，New Window 与 Dock 菜单的 New Window 都在当前窗口开一个标签页
- 引用、子模块、工作树、LFS、克隆与仓库管理的对话框是同一副骨架：宽 480，应用图标与单行标题，错误区带动画展开，Options 开关与选项区，底栏上方不画分隔线；服务器仓库在标题下写出位置
- 删除远端分支、添加与删除子模块、工作树与 LFS 传输的标题与主按钮；克隆对话框的两个勾选框直接在表单里，Initialize Submodules 默认勾上
- 新建与跟踪分支、获取、拉取、推送、发布、合并、同步、变基、安全强推与推送版本的对话框也是这副骨架：新建分支的标题是 Create New Branch，跟踪远端分支的主按钮是 Create，推送按本地分支是不是 HEAD 写 Push HEAD 或 Push Branch，同步的主按钮是 Sync HEAD；推送宽 450
- 对话框表单里的下拉填满输入列，不超过各自的上限；发布分支、发布标签、同步、安全强推与推送版本的 Skip Hooks 与说明相隔 4 pt；合并可行性预览在表单最后，安全强推的提交数在各自的下拉下方
- 改写、版本、储藏、工作区文件与外部工具选择的对话框也是这副骨架：组合框与输入框填满输入列，改写提交信息的标题写 Edit Commit Message of Revision “<短哈希>”，自动储藏用备选底栏；服务器上会改写历史的对话框在说明后另起一段，写明在哪台服务器上执行
- 添加服务器仓库的表单同样是这副骨架，标题不带省略号；体检失败时错误区写修复方向与原文，路径不存在或不是工作区时底栏多出 Create Repository；第一次连接时的环境变量提醒只有 Close
- 丢弃、删除储藏、恢复文件、移除 LFS 规则、远端设置、Reflog 恢复分支、续载提交与身份的确认是骨架的确认版，只有头部与底栏：标题是名词短语，主按钮写动作；丢弃一个文件时说明写出文件名，丢弃全部的标题是 Discard All Local Changes
- 丢弃块与行的确认在本机仓库同样有 Do not ask me again，与 General 页的 Warn when discarding changes in a chunk 是同一项；服务器仓库其余确认的 Do not ask me again 也在内容区；合并没有暂存的改动时，提交前的询问仍是系统提示框

## 准备

本机的测试目录放在系统临时目录下，测试结束后删除。Git 只读写这里的一份全局配置：

```sh
m14_root="$(mktemp -d "${TMPDIR:-/tmp}/spooky-m14.XXXXXXXX")"
mkdir "$m14_root/config"
export GIT_CONFIG_GLOBAL="$m14_root/config/gitconfig"
export GIT_CONFIG_NOSYSTEM=1
git config --global init.defaultBranch main
git config --global user.name 'Spooky Test'
git config --global user.email 'spooky@example.invalid'
git config --global commit.gpgSign false

# alpha/demo 与 beta/demo 同名，alpha/demo 里有一个储藏、一处改动与一个未跟踪文件，远端是临时的裸仓库
for parent in alpha beta; do
    mkdir -p "$m14_root/$parent/demo"
    git -C "$m14_root/$parent/demo" init -q
    printf 'one\n' > "$m14_root/$parent/demo/a.txt"
    git -C "$m14_root/$parent/demo" add a.txt
    git -C "$m14_root/$parent/demo" commit -q -m first
done

git init -q --bare "$m14_root/remote.git"
git -C "$m14_root/alpha/demo" remote add origin "$m14_root/remote.git"
git -C "$m14_root/alpha/demo" push -q -u origin main
git -C "$m14_root/alpha/demo" push -q origin main:feature
git -C "$m14_root/alpha/demo" tag v1.0

printf 'stashed\n' > "$m14_root/alpha/demo/a.txt"
git -C "$m14_root/alpha/demo" stash push -q -m 'm14 stash'
printf 'changed\n' > "$m14_root/alpha/demo/a.txt"
printf 'new\n' > "$m14_root/alpha/demo/new.txt"

# 不是仓库的普通文件夹
mkdir "$m14_root/plain"
```

## 主菜单

1. Spooky 菜单：Settings… 与 Hide Spooky 之间是 Services ▸，两侧各一条分隔线；在提交信息里选中一段文字后，Services 里列出系统可用的服务。
2. File › Open Recent：列出 `demo — alpha` 与 `demo — beta`，悬停提示是完整路径；末尾隔一条分隔线是 Clear Menu。选 Clear Menu 后菜单里只剩一项不可用的 Clear Menu；仓库管理里两个书签都在，书签详情的 Last Opened 不变。再打开 `alpha/demo`，Open Recent 只列出 `demo`。
3. Edit 菜单依次为 Undo、Redo ｜ Cut、Copy、Paste、Paste and Match Style ⌥⇧⌘V、Delete ⌘⌫、Select All ｜ Reformat Paragraph ⇧⌘W ｜ Find、Spelling and Grammar、Substitutions、Transformations、Speech；系统在其中与末尾加的项不在核对之内。
   - Find 子菜单：Find… ⌘F（按住 ⌥ 为 Search ⌥⌘F）、Find Next ⌘G、Find Previous ⇧⌘G、Use Selection for Find ⌘E、Jump to Selection ⌘J
   - Substitutions 里的项都不带快捷键
4. 提交信息的标题里输入几个单词并全选：Spelling and Grammar、Substitutions、Transformations 与 Speech 的项可用，Make Upper Case 把文字转成大写，Start Speaking 朗读选中的文字。
5. Spooky › About Spooky › License：选中第一个词 “GNU” 后按 ⌘E 再按 ⌘G，选中跳到下一处 “GNU”；⇧⌘G 跳回上一处。
6. ⌘⌫ 的行为：
   - 工作区文件列表选中 `new.txt` 按 ⌘⌫：文件移进废纸篓，与改动前相同；Edit › Delete 在这里不可用
   - 仓库管理的书签列表选中一个书签按 ⌘⌫：询问是否删除这个书签，与改动前相同；点 Cancel
   - 储藏列表选中 `m14 stash` 按 ⌘⌫：询问删除所选储藏，点 Cancel 后储藏还在
   - 提交信息的标题里输入 “hello world” 按 ⌘⌫：删到行首；选中其中几个字母再按 ⌘⌫：只删掉选中的字母；两者都与改动前相同
7. Repository 菜单：Fetch… ⇧⌘F、Fetch All Remotes、Pull… ⇧⌘P、Sync… ⇧⌘Y 一组，分隔线之后是 Push HEAD… ⇧⌘U、Force Push with Lease… ⌃⌘U、Push To…、Publish Branch…、Publish Tag…、Publish Repository…；按住 ⌥ 时 Push HEAD… 换成 Quick Push HEAD。Create New Branch… ⌘B；LFS ▸ 的 Fetch、Pull、Push、Track 不带省略号。
8. 按 ⌃⌘U 打开 Force Push with Lease 对话框，点 Cancel；View › Working Copy Status › Show Assume-Unchanged Items 不带快捷键。
9. Working Copy 菜单依次为 Checkout Revision… ｜ Merge…、Rebase…、Rebase Onto…、Apply Patch… ｜ Save Stash…、Apply Stash…、Create Snapshot… ｜ Discard All Local Changes…、Reset HEAD to Revision… ｜ Commit…、Stage、Unstage、Stage All Local Changes ⇧⌘E、Unstage All Local Changes ⌥⇧⌘E ｜ Discard Local Changes ⇧⌘⌫ ｜ Compare ▸；右键菜单与详情区按钮里的同名项写法不变。
10. View 菜单：
    - Working Copy Status 的前两项是 View As Tree ⌃⌘T、View As List ⌃⌘L，工作区状态头的视图设置菜单写法相同
    - History › Diffs in Changeset：Expand All、Collapse All 之后的分隔线下面是灰色不可选的 Auto-Expand Threshold，再是 Never Auto-Expand 到 Always Auto-Expand 八项
    - 在仓库窗口按 ⌃⌘R 显示仓库管理：Show Working Copy 到 Show Reflog（⌘1–⌘6）与 Show HEAD Branch ⌘0 都不可用，按对应的快捷键没有反应；Back ⌘[ 可用，回到仓库后这些项恢复可用
11. Window 菜单：Minimize ⌘M、Zoom，分隔线，Activity ⌃⌘0，分隔线，Bring All to Front；系统在缩放之后加的窗口排布项不在核对之内。

## 工具栏

在 `alpha/demo` 的窗口里核对。

1. 右键工具栏选 Icon and Text：侧边栏上方的入口写 Bookmarks，后退 / 前进写 Prev / Next，储藏两段写 Apply / Save。悬停的提示依次为：
   - Bookmarks：Navigates to Bookmarks view；Prev / Next：Navigates to the previous view / Navigates to the next view；Quick Actions：Shows Quick Actions
   - Fetch / Pull / Push：Fetches remotes / Pulls remote branches / Pushes local branches to remotes；Sync：Sync HEAD with a remote branch
   - Merge / Rebase：Merges another branch into the HEAD branch / Rebases the current HEAD branch onto another branch
   - Apply / Save：Reapplies changes to your working copy / Stores your local changes on the Stash；Refresh、Close Repository 与标签相同
2. 按住 ⌥ 悬停：Fetch、Pull、Push、Sync、Merge、Rebase 依次为 Immediately fetches remotes、Pulls the tracking remote branch、Pushes the HEAD branch to its tracking branch、Syncs the HEAD branch with its tracking branch、Merges the tracking branch of the current HEAD branch、Rebases the current HEAD branch onto its tracking branch，前面不带 “Quick …: ”；松开 ⌥ 后复原。
3. 右键工具栏选 Icon Only：提示变为 “Bookmarks: Navigates to Bookmarks view” “Prev: Navigates to the previous view” “Fetch: Fetches remotes” “Apply Stash: Reapplies changes to your working copy” 这样带标签的写法；Sync、Refresh 与 Close Repository 不带。按住 ⌥ 时依次为 “Quick Fetch: Immediately fetches remotes” 到 “Quick Rebase: Rebases the current HEAD branch onto its tracking branch”，Sync 也带 “Quick Sync: ”。
4. Customize Toolbar…：仓库管理入口在面板里叫 Bookmarks，Sync 叫 Synchronize；把 Create Branch、Force Push、Push To、Finder 与 Terminal 拖进工具栏后，只显示图标时的提示依次为 Create a new branch、Push using force-push with lease、Push To、“Finder: Show in Finder”、“Terminal: Open in Terminal”；核对完把工具栏恢复成默认排布。
5. Fetch 段的图标是朝左下的空心弧形箭头，与 Clone 的圆圈向下箭头不同；按住 ⌥ 点 Fetch 获取一次，Activity 窗口与侧边栏活动区里这条记录的图标与 Fetch 段相同。
6. 仍是 Icon Only：Working Copy 里工具栏上有一条竖线正对列表与 Diff 之间的分隔线，Quick Actions 起的各项排在竖线右侧；拖动这条分隔线，竖线跟着走。切到 History 同样如此；切到仓库设置时竖线消失，各项回到右侧的普通排布；切回 Icon and Text 时，Working Copy 里也没有这条竖线。
7. 把窗口逐渐拖窄：同步、合并、储藏与 Refresh 等先进 » 菜单，Bookmarks 与搜索框最后才进；工具栏里有 Create Branch、Force Push 时它们同样留到最后。
8. 按 ⌘R 后立即再按一次，或在刷新进行中点工具栏的 Refresh：两者都可用，刷新结束后状态正常。

## 窗口与仓库管理

在 `beta/demo` 的窗口里核对。

### 服务器

服务器上的测试目录只经 `spooky-test` 在 `/Users/wgy/spooky-test/` 下新建，测试结束后删除。服务器的场景由维护者在连得上 `spooky-test` 的 Mac 上验：

```sh
m14_ssh() { ssh -o BatchMode=yes spooky-test "$@"; }
m14_remote="$(m14_ssh 'umask 077; mkdir -p /Users/wgy/spooky-test && mktemp -d /Users/wgy/spooky-test/m14-app.XXXXXXXX')"
m14_ssh /bin/sh -s "$m14_remote" <<'EOF'
cd "$1"
git init -q -b main workspace
cd workspace
git config user.name 'Spooky Test'
git config user.email 'spooky@example.invalid'
printf 'one\n' > readme.txt
git add -A
git commit -q -m first
EOF
```

1. 在仓库管理窗口添加 `spooky-test` 上的 `$m14_remote/workspace` 并打开，再按 ⌃⌘R 回到仓库管理。
2. 执行 `m14_ssh "mv '$m14_remote/workspace' '$m14_remote/workspace-gone'"`，在仓库管理里打开 `workspace`：显示丢失页，不弹出错误。
3. 执行 `m14_ssh "mv '$m14_remote/workspace-gone' '$m14_remote/workspace'"`，切到别的程序再切回 Spooky：窗口自动换回仓库界面，期间不弹出询问凭据或口令的对话框。
4. 核对完执行 `m14_ssh "rm -rf '$m14_remote'"`。

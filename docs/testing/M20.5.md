# M20.5 焦点、列表与弹窗细节的验收

范围：方向键跟着键盘焦点走，历史列表的选中效果、日期写法与提交行分隔线，右侧变更文件的状态图标、行高、选中与分隔线，Working Copy 文件列表的行间分隔线，对话框显示期间高度变化的动画，工具栏去掉关闭仓库一项，Dock 图标的右键菜单列出最近打开的仓库。M1–M20 的验收步骤继续适用。

所有命令在仓库根目录执行。界面验收需要已解锁、显示器正常显示的 macOS 会话；截图在 2× 屏幕上，深色与浅色外观各做一遍，外观只用影响本次进程的启动参数切换，不改系统外观。

## 自动验证

```sh
mise run swift:lint
mise run build
mise run test
swift build --product Spooky
./scripts/build-app.sh
```

- `RepositoryFocusTests`：选中、刷新与读取完成不把焦点拉回侧边栏，打开仓库时焦点在侧边栏。
- `HistoryListTests+DateFormat`：今天、昨天、更早、跨日、时区与夏令时边界，作者日期与提交人日期不同时用后者，两种写法都核对。
- `HistoryListTests+FileSelection`：变更文件行的点选与方向键；行里三角以外的任何位置点下都点选这一行，点三角只展开、不点选；文件行 30 pt 高，选中底填满两条分隔线之间的整行。
- `DialogSizingTests`：经 `DialogWindow` 挂上的对话框一开始就是理想尺寸，错误区出现与内容区加行后窗口停在新的理想尺寸；可以拉大的窗口收起选项区时减去它的高度，再展开时回到收起前的高度；应用级模态会话里改尺寸不做动画，调用返回时已是新尺寸。
- `RepositoryDialogLayoutTests`：内容区最后一个控件与 Options 一行相隔 8，没有内容区时头部的说明与它也相隔 8，表单末尾没有内容的状态行不占高度；没有选项区时最后一个控件到底栏按钮是 12 + 12。
- `UserProfilesTests`：身份档案编辑框里 Signing Key 的下拉与输入框同宽、左右对齐。
- `SignatureViewsTests`：没有签名的标签打开签名弹窗，校验结果到达后弹窗变宽，放得下整句 “No Signature Found” 与两侧各 20 pt。
- `RecentRepositoryDocumentsTests`：本机仓库登记仓库文件夹，服务器仓库登记位置文件夹，两者都能读回原位置；Clear Menu 清空登记；测试不碰系统真实的最近文稿。
- `LocalizationTests`：八种语言的资源完整性与格式参数。

## 准备

用 `./scripts/build-app.sh` 生成的 `.build/Spooky.app`，或另做一个 Bundle ID 不同的测试包，避免写进自己的 `com.rakuyo.spooky` 的最近文稿。在临时目录建一个有几十个提交、几个分支与标签、工作区有增删改的测试仓库；服务器仓库用 `spooky-test` 上 `/Users/wgy/spooky-test/` 下新建的测试仓库。

## 焦点与选中

1. 打开测试仓库，焦点在侧边栏；按 ↑ ↓ 移动侧边栏的选中。
2. 点选历史列表的一行，再按 ↑ ↓：移动的是历史列表的选中，侧边栏的选中不变；等一次刷新（在仓库外改一个文件）后再按 ↑ ↓，仍作用于历史列表。再点侧边栏的一行，↑ ↓ 又作用于侧边栏。
3. 点选右侧变更文件的一行，⌘ 单击与 ⇧ 单击多选，按 ↑ ↓ 移动选中；刷新与提交详情读完后焦点不回到侧边栏。
4. 在变更文件行的上下边缘、三角的左侧与右侧、文件名右侧的空白处单击、⌘ 单击与 ⇧ 单击，结果与点在文件名上相同；点三角只展开或收起这个文件，选中不变。
5. 截图核对历史列表与侧边栏的选中效果：有焦点、没有焦点（焦点在别的列表）、窗口不活跃三种状态。

## 对话框高度变化

对下面每种情形录屏一次，逐帧核对：弹窗边缘与内容同时开始、同时结束；底栏始终贴着窗口底边，中间不露空白，正在淡出的内容不被裁掉；同一次更新的几处变化是一段动画。sheet 变高、变矮时上下两边各动一半。

1. Fetch、Pull、Merge、Push 等带 Options 的对话框展开、收起 Options。
2. 错误区出现、消失与换成更长的文字，如新建标签时输入不合法的名字再改对；Settings 里编辑身份档案时把标题改成另一个档案的标题、仓库设置里把每行字数上限设为 0，同样核对。
3. 打开对话框期间断开服务器仓库的连接再重连，`dialog.blocked` 一行出现、消失。
4. 合并预览换来源；Force Push 换分支；Rebase Onto 改基点；Reset 输入版本与切到 Hard；Checkout Revision 输入版本；Clone 输入地址、机器选 Other…；Scan 扫描失败后重新扫描；账号换认证方式与浏览器授权；合并 Pull Request 读取选项；发布仓库改所有者与名称。
5. 添加远端、新建标签、重命名引用、修改远端地址与新建工作树时连续输入：等待校验期间错误区与高度不来回跳。
6. Git 错误框收起原文区时窗口变矮，再展开回到收起前的高度。

## 对话框细节

1. 截图核对带 Options 的对话框：Fetch（含侧边栏远端右键的 Fetch）、Pull、Sync、Push、Force Push with Lease、Publish Branch、Publish Tag（含侧边栏标签右键的 Push To）、Create New Branch、Merge、Rebase、Rebase Onto（含提交右键）、Cherry-Pick、Revert 与 Save Patch。内容区最后一个控件（或合并预览、强推的核对状态，Save Patch 是头部的说明）与 Options 一行之间的间距处处相同，Options 一行到底栏按钮的间距也处处相同；Merge 没有冲突、Force Push 只落后时，最后一个勾选项或下拉下方不多出空白。
2. Settings › User Profiles 新建与编辑身份：Signing Key 的下拉填满输入列，左右两边与上面几行的输入框对齐。
3. 侧边栏标签右键 › Show Signature：弹窗出现在标签行的左侧（左侧放不下时在右侧）；没有签名的标签显示整句 “No Signature Found”，不被截成 “…”；有签名的标签是头像、姓名与邮箱，分隔线下方是 GPG Key 与 Status 两行，弹窗大小随内容。

## 工具栏

1. 默认排布与自定义面板里都没有关闭仓库一项；用带这一项的旧排布启动，载入后不显示。
2. File › Close Repository 仍可用。

## Dock

1. 把测试包固定到 Dock，先后打开本机测试仓库与服务器测试仓库，退出 Spooky。
2. 右键 Dock 图标：两个仓库都在列，图标都是访达的文件夹图标；点选其中一个，Spooky 启动并打开它。
3. Spooky 运行中再点选另一项：打开它，已开的窗口直接切过去。
4. Clear Menu 之后右键 Dock 图标，列表为空。
5. 结束后取消固定，清掉测试包的最近文稿，核对 Dock 固定项与测前一致。

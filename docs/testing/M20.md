# M20 应用图标的选择验收

范围：Settings › Appearance 的 “App Icon:” 一行与图标列表，满怀（默认）、满怀 · 素底、满怀 · 紫底、栖枝、采撷、服务器幽灵与午夜七组在运行中的 Dock、App 没运行时的 Dock、⌘Tab 与 Finder 里的显示，自定义图标的写入、清除与写不进去时的提示。M1–M19 的验收步骤继续适用。

下面的步骤以默认的满怀与午夜为例；满怀 · 素底、满怀 · 紫底、栖枝、采撷、服务器幽灵和午夜一样是非默认的组，凡写午夜的步骤对它们同样适用，各抽查一遍。

所有命令在仓库根目录执行。界面验收需要已解锁、显示器正常显示的 macOS 会话。切换 “图标与小组件样式”、外观与 Dock 固定项的步骤，结束后都改回原样，并核对系统里的状态确实恢复了。

## 自动验证

```sh
mise run swift:lint
mise run build
mise run test
swift build --product Spooky
mise run bundle
```

- `AppIconControllerTests`：偏好缺省、不认识的值与 Reset / Clear User Defaults 之后回到默认的满怀；默认的一组与午夜 × 默认、深色、自动、透明、色调样式 × 外观 × 连接状态，对应的运行时图标、底图来源与自定义图标，透明样式与色调浅色下自定义图标是午夜默认图标的原图、其余样式下是合成的一版；在临时目录的 App 上写入、清除自定义图标，写不进去时换组失败、偏好不变；写入在后台按顺序执行，主线程不等，Reset 之前发出的换组不覆盖 Reset 的结果；换组写完重启 Dock 一次，选回当前的组与写入失败时不重启；启动时写进了自定义图标、Reset / Clear 清掉了自定义图标时各重启一次，选着默认的一组或包上已是所选的组的启动与样式变化的重写不重启；几次请求先后排队时等全部写完再重启一次，换组还没写完时做 Reset 也重启，换走又换回时不重启（重启由测试注入，不碰真实的 Dock）。
- `AppIconControllerTests`：默认的一组是满怀，`CFBundleIconFile` 是它的默认图标；七组各四份 icns 都在，其它六组都写自定义图标，`scripts/make-icon-shells.sh` 给它们各写一个壳 App。
- `AppIconRendererTests`：七组的亮灯版与灭灯版只差亮起来的部分（满怀三组的眼睛，栖枝的果子，采撷枝上的节点，服务器幽灵的四盏灯，午夜的眼睛与光晕）；合成保留系统图标的亮度，只改目标与包内图标不同的地方，像素尺寸与系统图标相同。
- `AppIconSettingsTests`（需要辅助功能权限，没有时跳过）：列表读作 “App Icon:”，每组一行，只有所选的一行带选中状态；点一行换组失败时下方写出原因，各行恢复可用，组与偏好不变。
- `AppIconControllerTests`：关于窗口显示 `AppIconController` 记下的图标，换组后不用重新打开就跟着换。
- `LocalizationTests`：八种语言的资源完整性与格式参数。

## 准备

先退出正在运行的 Spooky，记下 “系统设置 › 外观” 的外观与 “图标与小组件样式”，以及 Dock 的固定项；验收用 `mise run bundle` 生成的 `build/Spooky.app`：

```sh
# 取解析过符号链接的路径，注销 LaunchServices 登记时与登记的路径一致
m20_root="$(cd "$(mktemp -d "${TMPDIR:-/tmp}/spooky-m20.XXXXXXXX")" && pwd -P)"
defaults read com.apple.dock persistent-apps > "$m20_root/dock-before.txt"
mise run bundle
open build/Spooky.app
```

启动后在 Dock 里对 Spooky 选 “选项 › 在程序坞中保留”，后面核对 App 没运行时的图标。

逐像素对照用只装一个 icns 的临时 App，Dock 把它的图标当包内图标画出来：

```sh
# 用法：m20_icon_app AppIconMidnightConnected
m20_icon_app() {
    local app="$m20_root/$1.app"

    mkdir -p "$app/Contents/MacOS" "$app/Contents/Resources"
    cp "Sources/Spooky/AppIcon/Icons/$1.icns" "$app/Contents/Resources/"
    printf '#!/bin/sh\n' > "$app/Contents/MacOS/$1"
    chmod 755 "$app/Contents/MacOS/$1"

    cat > "$app/Contents/Info.plist" <<PLIST
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>CFBundleExecutable</key>
    <string>$1</string>
    <key>CFBundleIconFile</key>
    <string>$1</string>
    <key>CFBundleIdentifier</key>
    <string>com.rakuyo.spooky.m20.$1</string>
    <key>CFBundlePackageType</key>
    <string>APPL</string>
</dict>
</plist>
PLIST

    printf '%s\n' "$app"
}
```

把临时 App 拖进 Dock 固定，截下它的格子，对照完从 Dock 移除。

## 设置页与图标列表

1. 打开 Settings › Appearance：外观一行下方是 “App Icon:” 一行，标签与 “Appearance:” 右对齐、与列表第一行的组名排齐；控件列里左侧是预览，右侧是列表，两者同高：
   - 预览是 160 pt 的大图与下方 Dock 的示意（五个格子，正中是 44 pt 的图标与运行指示点），都是所选的组在 Dock 里指示灯灭着的一版
   - 列表七行都露出来，自上而下是 Armful、Armful – Plain、Armful – Purple、Perch、Cherry Pick、Server Ghost、Midnight，每行是 30 pt 的小图标与组名，指示灯都灭着；Armful 一行是选中色
2. 指针移到 Midnight 一行：这一行浅灰底，预览的大图与 Dock 示意换成午夜，Dock 与选中的一行不变；移开后预览回到满怀。
3. 点 Midnight 一行：写入期间这一行灰底、右端转圈，各行不可点；写完选中落到 Midnight，Dock 重启一次，图标换成午夜。
4. 再点 Midnight 一行：没有变化，Dock 不重启。
5. 键盘：Tab 把焦点移到列表，↑ ↓ 移动浅灰底的一行，预览随之变化，到头不动；移到 Armful 后按空格，选中与 Dock 都回到满怀，Dock 重启一次。
6. 在 “系统设置 › 外观” 中切换浅色与深色外观，各看一遍这一行：
   - “图标与小组件样式” 为默认时，预览与列表都是浅色版
   - 深色选 “始终”，或选 “自动” 且系统为深色外观时，预览与列表换成深色版
7. VoiceOver：列表读出 “App Icon”，每一行读出组名，所选的一行带选中状态。
8. 退出后用 `open build/Spooky.app --args -AppleLanguages '(<语言>)'` 逐个以八种语言启动，核对组名与标签都完整显示，没有截断。

## 运行中的 Dock

1. 七组 × 默认 / 深色样式 × 连接 / 未连接，各截一张 Dock 格子的 2× 截图，与对应临时 App 的格子逐像素对照：
   - 满怀用 `AppIconArmful`、`AppIconArmfulConnected`、`AppIconArmfulDark`、`AppIconArmfulDarkConnected`
   - 满怀 · 素底、满怀 · 紫底、栖枝、采撷与服务器幽灵照此类推，前缀分别是 `AppIconArmfulPlain`、`AppIconArmfulPurple`、`AppIconPerch`、`AppIconCherryPick`、`AppIconServerGhost`
   - 午夜用 `AppIconMidnight`、`AppIconMidnightConnected`、`AppIconMidnightDark`、`AppIconMidnightDarkConnected`
   - 连接状态：打开测试服务器上的仓库；断开或关闭最后一个服务器仓库后指示灯熄灭
2. 选中午夜，连上测试服务器的仓库：Dock 里午夜的眼睛与光晕亮起；断开后熄灭。其余六组亮起来的分别是：满怀三组的眼睛，栖枝枝头的果子，采撷枝上的节点，服务器幽灵机架上的四盏灯。
3. 透明与色调样式的 “浅色” “深色” “自动” 下：
   - 选中满怀时，按 [M12](M12.md) 的 “Dock 图标” 核对，不换运行时图标
   - 选中午夜时，Dock 显示系统按样式处理过的午夜图标，连上服务器仓库也不亮
   - 把每种样式下看到的结果写进验收记录
4. 打开关于窗口与启动窗口：图标与运行中的 Dock 相同；窗口开着时换组、连上或断开服务器仓库，图标随之更新；之后打开的对话框头部也是这一张。

## App 没运行时

1. Spooky 固定在 Dock 里时选中午夜：Dock 重启，约 1 秒后恢复。退出 Spooky：
   - 固定在 Dock 里的图标是午夜，大小与亮边与运行中的 Dock 相同
   - Finder 里的 `build/Spooky.app` 是午夜
   - `ls -la build/Spooky.app` 能看到包根的 `Icon?`；`codesign --verify --deep build/Spooky.app` 通过
2. 再次启动：Dock 不重启；按 ⌘Tab，切换器里是午夜，指示灯灭着。
3. 选回满怀（Dock 再重启一次）后打开关于窗口与启动窗口，图标都是满怀；退出：Dock、Finder 与 ⌘Tab 都恢复满怀，包根的 `Icon?` 消失，`codesign --verify --strict --deep build/Spooky.app` 通过。
4. 选着午夜时切换 “图标与小组件样式” 或外观：包根的自定义图标重写成当前样式的一版，Dock 不重启，固定的格子仍是午夜。
5. 透明与色调样式的 “浅色” “深色” “自动” 下，各从满怀换到午夜（Dock 随之重启）再退出：
   - 固定着的格子是 Dock 按样式处理过的午夜，不发暗、不发黑
   - 色调深色下是系统按样式处理过的午夜图标，与运行中的画法相同
   - 把与运行中的格子的差别写进验收记录

## 壳 App

1. 用聚焦搜索 `AppIconArmfulPlain`、`AppIconArmfulPurple`、`AppIconPerch`、`AppIconCherryPick`、`AppIconServerGhost`、`AppIconMidnight`，启动台里查找这六组的图标，在 Finder 里对一个文件打开 “打开方式”：都不出现壳 App。
2. `build/Spooky.app` 放在会被聚焦收录的位置（如 `/Applications`）时再查一次。

## 写不进去时

1. 把 `build/Spooky.app` 做成只读的磁盘映像并从映像里启动：

   ```sh
   hdiutil create -srcfolder build/Spooky.app -format UDRO "$m20_root/Spooky.dmg"
   hdiutil attach "$m20_root/Spooky.dmg"
   ```

2. 在 “App Icon:” 一行点另一组：预览与列表下方写 “Couldn't switch the icon because it can't be written to Spooky.app.”；选中的一行、Dock 与偏好 `defaults read com.rakuyo.spooky appIconGroup` 都保持原来的组，Dock 不重启。
3. 退出 App，`hdiutil detach` 卸掉映像。

## Sparkle 更新

选中午夜、包根有 `Icon?` 时，用可用的更新源检查、下载并安装一次更新，再启动：能正常安装，启动后包根写回午夜的自定义图标，Dock 重启一次，固定在 Dock 里的图标与 Finder 都是午夜。没有可用的更新源时，在验收记录里列为未验证。

## Reset User Defaults

Reset 会删掉 Spooky 的设置，这一节放在收尾之前。

1. 选中午夜，Settings › General 勾上 Show Developer menu，点 Developer › User Defaults › Reset User Defaults 并确认：这一行回到满怀，包根的 `Icon?` 消失，Dock 重启一次。
2. 退出 Spooky：固定在 Dock 里的格子是满怀。

## 收尾

1. 选回满怀，退出 Spooky。
2. 把外观、“图标与小组件样式” 改回准备时记下的值，从 Dock 移除临时 App，核对 Dock 的固定项与准备时相同：

   ```sh
   defaults read com.apple.dock persistent-apps | diff "$m20_root/dock-before.txt" -
   ```

3. 删掉临时 App，再注销它们的登记：

   ```sh
   lsregister=/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister
   m20_apps=("$m20_root"/AppIcon*.app)

   # 先删文件再注销：放在会被索引的位置时，系统会在删文件之前把注销掉的登记补回来
   rm -rf "${m20_apps[@]}"
   for app in "${m20_apps[@]}"; do "$lsregister" -u "$app"; done

   # 应为 0
   "$lsregister" -dump | grep -c 'com.rakuyo.spooky.m20'
   ```

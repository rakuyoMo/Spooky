# M15 Diff 与文本验收

范围：语言识别、语法记号、主题颜色、文件详情头部、目录文件历史、变更集摘要、菜单路由与自动展开、块内文本选择与动态行号栏、组合 Diff 的多父列、文件头摘要与大 Diff 警告，以及工作区单文件补丁与快照边界。

所有命令在仓库根目录执行。界面验收使用临时仓库，需要已解锁、显示器正常显示的 macOS 会话。

## 自动验证

```sh
mise run swift:lint
mise run build
mise run test
swift build --product Spooky
./scripts/build-app.sh
```

- `SyntaxHighlighterTests`：完整文件名与扩展名、头文件语言、20,000 个字符边界、全部语言自动识别、非法记号回退、Diff 两侧独立识别、语法颜色与 UTF-16 片段长度。
- `ThemeColorSpaceTests`、`ThemeAndTerminalTests`、`ThemeStoreTests`、`FileViewsTests` 与 `DiffDisplayTests`：直接主题色、推导色与命名色的空间边界，面板转换、透明度与重复写入，真实文本和色块的颜色。

- `FileHeaderTests`：原生动作分段、比较侧的整体与逐段可用性、目录历史的字面路径、重命名的树形与平铺文案。

- `FileHistoryDirectoryTests`、`FileHistoryDirectorySourceTests`：目录多文件的实际语法与图片对象、移动方向、外部比较进程读取的两侧缓存、对象类型与内容动作、Unicode 路径、单项放行与恢复。
- `FileHistoryDirectoryLoadingTests`：单项失败与重试、不同上下文 / 空白选项的连续更新、同路径目标切换、关闭与迟到结果隔离，以及 Activity 的 Finished / Failed / Cancelled。
- `SingleFileDiffTests`、`FilePathEnvironmentTests`：文件与目录互换、符号链接的多段补丁、精确单文件范围，以及污染路径环境下的真实读取与写入隔离。
- `WorkingCopyStatusRecordsTests`：真实 SHA-1 / SHA-256 原始状态、重命名双 NUL、重复路径、冲突 / 子模块 / 忽略记录的过滤与严格格式错误。
- `WorkingCopyScopeTests`：祖先重命名双方向与旁支、特殊路径、动态范围有界重读、查询数量、旧条目与第二次快照校验；暂存 / 取消暂存 / 丢弃的块 / 单行 / 多行、忽略空白，以及成功 / 拒绝 / Git 两阶段失败 / 取消后的独立旧文件保护。
- `UndoSessionTests.independentRenamePath`：无窗口的真实会话按块入口及撤销采样包装，成功和失败均逐字节保护旧路径独立文件。

- `ChangesetPresentationTests`、`ChangesetExpansionTests`：独立计数单复数、缺失统计、整页空行与提交 / 比较 / 储藏的部分展开。
- `ChangesetEmptyStateTests`：读取失败不显示成功空行，空比较 / 空储藏实际呈现零摘要，以及加载行、转圈与文字的辅助功能尺寸和位置。
- `ChangesetCommandTests`：六种可见详情的命令路由、禁用时的直接动作保护、Reflog 内容与历史比较隔离，以及请求详情的获取边界。
- `ChangesetAutoExpandTests`、`MainMenuTests`：八档全局菜单、阈值边界、当前展开与缓存保持、tracked / untracked 储藏来源，以及切对象和关闭后的迟到清单。
- `DiffTextLayoutTests`、`DiffTextCopyTests`：逐列行号与宽度、折行与空片段、原文复制映射、独立字符选区、语法 / 行内底色、行号键盘与辅助功能入口，以及五万行完整排版。
- `CombinedDiffTests`、`CombinedDiffDisplayTests`：真实 Git 两父 / 三父夹具的完整范围与逐侧行号、空侧、不同父长度、多块、CRLF、特殊路径、损坏输入与只读保护；任意列宽度、符号、折行和复制。
- `DiffFileMetadataTests`、`HistoryCopyTests`：真实扩展头、模式、重命名路径解码、多父模式、可选字段损坏，以及历史 / 比较中副本按新增显示。
- `DiffSummaryTests`、`DiffSummaryLayoutTests`：摘要顺序与统计、八语言资源、固定字体、实际折行与复制、居中底栏、内联警告高度和按钮边界。
- `LocalizationTests`：八种语言的资源完整性与按实际参数位置比较的格式签名。

## 语法着色

1. Settings → Text 打开 Enable Syntax Coloring 与 Syntax Coloring in Diffs。
2. 工作区查看 `Bridge.h` 与 `Vector.h`：前者的 `@interface`、`@end` 为关键字色，后者的 `namespace`、`template`、`typename`、`struct` 为关键字色。
3. History 选中第一条提交，在只读 Diff 中逐个核对：
   - `project.pbxproj` 整份按纯文本显示。
   - `area.jl` 的 `function`、`return`、`end` 和 `square.ml` 的 `let` 为关键字色。
   - `Localizable.strings` 的注释与字符串分别着色。
   - `page.html` 的两个属性值使用属性值色；`app.js` 的 `render` 使用函数色，`/a+b/g` 与 JSX 内的 `run` 使用正文色，JSX 的 `"a"` 使用属性值色。
   - `data.json` 的括号与逗号使用符号色。
   - `build` 按 Dockerfile 着色；`big` 超过 20,000 个字符，按纯文本显示。
4. 逐个打开 View File 与 Blame，核对相同记号与 Diff 的颜色类别一致。工作区有未提交修改时，原文与 Blame 显示的是提交过的版本。
5. 在 Themes 页复制主题，将 Function、Symbol、Attribute Value 设为三种明显不同的颜色，并选用复制后的主题。函数名、运算符与标点、属性值分别随对应颜色变化，普通字符串与其它标识符不变。
6. 分别在浅色与深色外观截图，核对文本完整、颜色清晰，切换文件或关闭视图不会把旧着色套到新内容上。

## 主题色的色彩空间

1. 分别选用 Default 与 Default (Dark)，核对工作区 Diff、History 的只读 Diff、原文与 Blame 的正文、背景、语法色及增删底色；直接主题色均按 Generic RGB 显示，行号、块描边、Blame 的段高亮与分隔线仍按原始 sRGB 分量推导。
2. Settings → Themes 的记号列表、选中行、字体颜色色块与 Diff 预览使用同一套直接主题色。深色主题背景 `#161819` 不应被当作 sRGB 分量直接显示。
3. 在本次复制的测试主题上打开系统颜色面板，改变一种中间色与不透明度。切换记号、切换主题、关闭再打开设置，颜色与保存的六位十六进制、两位不透明度不应反复漂移；未改动颜色时不重复写盘。
4. 文本选择的底色跟随主题，文件状态徽标、行内高亮等命名色不随主题构色方式改变。用同一显示管线的色样比较截图，保留截图的色彩配置，不把不同配置下的原始像素值直接对比。

## 文件详情头部

1. 在工作区分别选中已暂存、未暂存、双侧修改和未跟踪文件。头部高 40 pt，左侧 24 × 24 的系统类型图标距左边 20 pt；文件名为 13 pt 粗体，只写末级名称，完整相对路径在提示中。
2. 移入头部，Blame、File History、Diff Tool 分段组淡入；移出淡出，Tab 焦点仍能显示并触发动作。右键头部列出同样动作；比较侧控件使用圆角，未跟踪文件整组禁用且选在 Unstaged。
3. 选择 Staged 后打开 Diff Tool，核对索引相对 HEAD；选择 Unstaged 后核对工作区相对索引。重命名时已暂存侧左版使用旧路径，未暂存侧使用新路径。
4. 切为树形并选目录，头部显示文件夹和末级名称、隐藏比较侧；只有 File History 可用。空状态使用文件符号，被忽略目录保留专属说明。
5. 文件历史详情头部依次提供 Blame、Show Commit、Diff Tool；原文与 Blame 仍提供 File History、Show Commit。主头和贡献者行在浅色、深色与非活跃窗口下使用头部材质与内嵌底线。
6. 重命名的平铺行显示完整旧路径 → 完整新路径；树形行显示完整旧路径 → 新末级名称，仍属于新目录，提示保留两边完整路径。复制条目不显示箭头。
7. 首次读取 Diff 时内容为空白；同文件刷新保留旧 Diff，底栏不出现加载转圈。文件历史仍显示正常的加载提示。Pull Request 评论的附件动作始终为独立按钮。

## 目录文件历史

1. 在目录内同时修改多个文本文件和图片，另改目录外与同前缀的相邻目录。打开目录的 File History，选择提交，右栏按真实路径列出目录内所有变更，图片、语法着色与重命名均使用各自来源。
2. 创建文件 → 目录、目录 → 文件和目录删除的提交。Raw、头部 Blame、时间线与文件菜单的原文 / Blame / Export 按所指提交对象的能力启用；目录与未解析目标禁用，删除文件仍显示缺失说明。Show Commit、比较与恢复保留各自能力。
3. 从当前提交之外的时间线条目打开比较，比较目标仍是右键所指提交；移出和移入目录的文件保持新旧路径，根提交的旧侧为空。恢复目录需要确认，确认后目录内全部文件恢复。
4. 设置较低的大 Diff 阈值，放行一项时其它项保持原状态。一个文件失败不遮住其它结果，Retry 只重读该文件。滚动回已读文件不重复读取；修改上下文或忽略空白重读可见文件。
5. 快速切提交、换目标、关闭仓库及连续修改显示设置，旧读取不能覆盖新结果或清掉新请求。普通文件历史、后退 / 前进与文件历史链接仍可使用。
6. 临时仓库中的 `node` 与 `node/sub/a.txt` 互换时，每项补丁只包含对应文件，目录旁支不重复；特殊字符、NFC / NFD 与大小写路径都保持真实身份。

## 提交详情的变更集

1. 在至少有两个变更文件的提交、两版本比较与储藏详情中，先全部折叠，再仅展开一个文件。按钮仍为 Expand All；点击后保留已展开文件并展开其余文件，再点击 Collapse All 全部折叠。
2. 摘要始终显示文件数、新增数与删除数，三段分别选择单复数；折叠不改变总数。仅二进制与组合 Diff 的未知统计按零累计，储藏包含已跟踪与未跟踪文件。
3. 缩窄窗口：32 pt 摘要栏的按钮保持完整，11 pt 次要文字先从尾部截断；选择和复制摘要得到完整文字。
4. 展开尚未缓存的文件，核对加载行高 32 pt、转圈为 16 × 16 且距左 3 pt，13 pt 禁用色文字左缘位于 25 pt。整体文件列表加载与单文件加载各自保留反馈。
5. 选中空提交、相同版本的比较与空储藏变更集，只有完整的零摘要，不出现额外的 No text changes。双击空提交进入整页详情，左栏首行显示居中的 No changes.，高 42 pt、13 pt；加载或失败不显示这行。
6. 在各入口核对重命名文件仍显示旧路径 → 新路径。

## 变更集菜单与自动展开

1. 打开 View → Diffs in Changeset，核对 Expand All（⌃⌘→）、Collapse All（⌃⌘←）、分隔线、不可选的 Auto-Expand Threshold，以及 Never、5 / 10 / 15 / 20 / 25 / 50、Always 八档；只有当前档位打勾，没有 ⌥ 变体。
2. 在 History、版本比较和单选储藏中，先展开一个文件，分别用菜单和快捷键全部展开、全部折叠。只改变当前可见详情，隐藏的提交、储藏与其它比较保留原范围。
3. History 的 Tree、整页单文件、无选择和多选，比较的 Commits，文件列表读取中、空结果或失败无文件时，两条命令都不可用。比较来自历史多选时，Changeset 仍可操作；Commits 不回退到背后的提交。
4. 保留一个历史比较后打开 Reflog，切换记录并展开文件，内容与动作只使用 Reflog 的提交；返回 History 时原比较仍在。分支整理的单选 Changeset 同样只改变自己的比较，多选或所选分支消失时不可用。
5. 在测试托管项目的 Pull Request / Merge Request 详情中，Changeset 使用自己的比较；Conversation、Commits、需要获取或没有详情时不可用。自动回归使用隔离响应，不调用真实托管服务。
6. 分别保持全折叠、部分展开和全展开，修改 Never / Always：当前范围不跳变，也不额外读取补丁。切到另一个提交、比较或储藏并读完清单后才应用新档位；恰好等于阈值时展开，超过阈值不展开。
7. 储藏包含已跟踪与未跟踪文件，自动展开后两类补丁来自各自保存的版本。快速切换对象或关闭仓库，旧读取不能展开或覆盖新详情。
8. 回到仓库管理或关闭仓库窗口，八档阈值仍可设置且勾选正确；没有可见变更集时，展开 / 折叠不可用。

## Diff 块的文本区与行号栏

1. 在工作区打开同时含上下文、增删、空行、Tab、CRLF、长行与末行无换行的文件。核对删除行旧列带 `-`、新增行新列带 `+`、相同列号去重；文件开头的另一侧锚点显示 `0`。
2. 缩窄并放宽窗口，确认长行自动折行，行号只在第一视觉行出现；点击折行下半部仍选择同一逻辑行，末尾空白不选择补丁行。更换字体时行高、列宽和折行一起改变。
3. 跨行拖选并用 ⌘C 复制，回读剪贴板核对选中的字符；单行局部选择不扩成整行，整块全选保留源串末尾 LF。打开 / 关闭不可见字符后分别核对原始 Tab、空格、CR、CRLF 与字面上的 `·`、`→`、`¬`。
4. 先选正文，再通过行号和块头操作，确认行号选择不清空字符选区。切换主题后文字选区保持、选区色更新，语法色与行内底色同时可见。
5. 无换行提示独立成行、行号为空，显示 Git 原文去掉开头反斜线；按逻辑行暂存、取消暂存和丢弃仍处理正确行。
6. 通过 Tab 进入行号栏，用 ↑ / ↓ 移动焦点、Space 切换选择；使用 VoiceOver 聚焦和按下行号，核对选中值与禁用状态。只读 Diff 和 Themes 预览仍可复制文字，但不提供行号写操作。

## 工作区单文件补丁与快照

1. 在临时仓库把文件 `node` 重命名为 `node/sub/a.txt`，另建同级及深层旁支，再编辑新文件。Staged 只显示真实重命名，Unstaged 只显示新文件；按块暂存后核对新文件索引与旁支原文。反向重命名同样保持单文件范围。
2. 对 `old → new` 的已暂存重命名，在旧路径新建独立未跟踪文件。仅改旧文件内容后，原新文件 Diff 仍可按块操作；核对旧文件的原始字节与未跟踪状态不变。旧文件出现、消失或加入索引，以及新文件或索引改变时，旧快照必须拒绝写入。
3. 文件与目录互换时只显示对应叶文件；无法写入的索引结构保留 Git 错误，不删除旁支。普通文件与符号链接互换形成多段补丁时可查看，但按块 / 行写入必须拒绝。
4. 外部操作发生在读取或确认期间时，旧快照不能写到另一重命名目标。范围变化、预检后变化及取消用自动测试的命令闸门验证，不依赖人工竞争时序。

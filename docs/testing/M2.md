# M2：服务器仓库、连接状态与设置验收

M2 建立服务器仓库的执行与连接基础。M1 的本机仓库验收继续适用；M3–M10 是 `1.0.0` 的后续交付范围。

## 自动验证

在仓库根目录执行：

```sh
swift build
swift test
swift build --product Spooky
./scripts/build-app.sh
```

默认测试不访问 B。远端验收必须显式启用：

```sh
SPOOKY_REMOTE_TESTS=1 swift test
```

远端测试固定使用 `spooky-test`、`~/.ssh/spooky-test_ed25519` 和 `IdentitiesOnly=yes`，关闭 agent 转发和 PTY。测试仅在 `/Users/wgy/spooky-test/` 下创建独立子目录，结束后删除；Git 身份写入测试仓库本地配置，忽略用户全局配置。

集成测试覆盖：

- 首次体检、状态读取、特殊字符路径、stdin 提交信息、子目录与工作区根会话复用。
- 未知与变化的指纹、认证失败、路径不存在、无工作区、目录权限、Git 缺失、低版本和损坏的状态格式。
- 同仓库写操作串行、排队取消、活动进程组的 TERM / KILL 与退出确认。
- 仅关闭 Spooky 主连接的主动断线、中断写入不重试、重连后核对仓库。
- Git 自身退出 255、Git askpass、SSH askpass 请求通道、编辑器回调及凭据脱敏。
- 远端程序和会话目录的 `0700` 权限、关闭后的远端会话清理。

本机协议测试另覆盖错误帧跨块解析、伪造令牌、一次性应答、过期操作拒绝和跨块凭据脱敏。SSH askpass 通道测试不访问外部 Git 服务，也不等价于真实的 B 侧加密私钥登录验收。

## 准备 App 测试仓库

使用以下命令在 B 的允许目录内创建独立工作区；输出的路径供添加表单使用。若连接失败，记录未验证，不调整网络或 sshd。

```sh
/usr/bin/ssh -T -a -S none \
    -o ControlMaster=no \
    -o BatchMode=yes \
    -o StrictHostKeyChecking=yes \
    -o IdentitiesOnly=yes \
    -o IdentityAgent=none \
    -i "$HOME/.ssh/spooky-test_ed25519" \
    -- spooky-test /bin/sh -s <<'REMOTE'
set -eu
umask 077

test -d /Users/wgy/spooky-test || mkdir -m 700 /Users/wgy/spooky-test
spooky_case=$(mktemp -d /Users/wgy/spooky-test/m2-app.XXXXXXXX)
spooky_worktree="$spooky_case/仓库 with spaces"
mkdir "$spooky_worktree"

export GIT_CONFIG_GLOBAL=/dev/null
export GIT_CONFIG_SYSTEM=/dev/null
export GIT_CONFIG_NOSYSTEM=1

/usr/bin/git -c init.templateDir= init -q --bare "$spooky_case/origin.git"
/usr/bin/git -C "$spooky_worktree" -c init.templateDir= init -q -b main
/usr/bin/git -C "$spooky_worktree" config --local user.name 'Spooky Test'
/usr/bin/git -C "$spooky_worktree" config --local user.email spooky@example.invalid
/usr/bin/git -C "$spooky_worktree" config --local commit.gpgSign false
/usr/bin/git -C "$spooky_worktree" remote add origin "$spooky_case/origin.git"

printf 'first file\n' > "$spooky_worktree/你好 [draft].txt"
printf '%s\n' "$spooky_case" "$spooky_worktree"
REMOTE
```

清理时先在 App 中关闭该仓库，再通过相同 SSH 选项，仅删除刚输出的 `/Users/wgy/spooky-test/m2-app.XXXXXXXX`。不要使用通配符删除其它测试目录。

## App 冒烟与恢复

1. 执行 `swift run Spooky`，截图确认管理页空状态。按 [M1](M1.md) 完成本机打开、分支、状态、刷新、选择文件、关闭和窗口复用验收。
2. 从空状态、底部 “+” 菜单和 File 菜单分别进入添加服务器表单。输入 `spooky-test` 与上一步工作区路径，确认体检中的控件禁用和取消操作。
3. 分别尝试空别名、相对路径、不存在路径和非 Git 目录。确认失败保留表单输入、具体修复方向、退出码和 stderr，不产生书签。
4. 打开有效路径。确认标题、工具栏主机标识和书签都带 `spooky-test:`，Working Copy 与本机使用同样的分支和状态视图。
5. 新开窗口显示本机仓库，同时保留服务器仓库窗口。重复打开同一服务器工作区应激活已有窗口；显式 “在新窗口打开” 仍创建独立窗口。
6. 在本次测试目录新增文件。前台窗口约 2 秒后更新，后台窗口约 10 秒后更新；重新激活立即刷新。刷新中旧快照和仍存在的选区保留。
7. 从 Spooky 自己启动的 SSH 进程参数确认专属 `-S /tmp/spooky-…/master.sock`。仅对该 socket 执行 `ssh -S <该路径> -O exit -- spooky-test` 模拟断线；不得使用用户 `~/.ssh/cm-*` 的控制连接。
8. 确认 App 不退出，旧列表仍可读，连接状态可观察，后台重连成功后更新。连接失败时可展开原始 SSH 诊断；中断的写操作不重试，核对结果包含分支、改动数量、锁和合并 / 变基状态。
9. 关闭最后一个使用该仓库的窗口或退出 App，确认该主连接与会话目录被清理，用户其它 SSH 连接保持可用。

断线写入及进程组取消由集成测试覆盖；M2 没有提交、暂存、Fetch / Pull / Push 等 Git 写操作按钮。

## 终端与路径

1. 按 ⌘, 打开 Settings，查看 General 的终端选择。确认候选来自本机已安装的受支持程序，显示名称和图标，选择后立即生效并在重启后保留。
2. 分别选择 Terminal 与 Otty，从主菜单、工具栏的 Terminal 项（经 View › Customize Toolbar… 加入）、Working Copy 右键和书签右键执行 “在终端中打开”。本机执行 `pwd`，核对特殊字符路径完整保留。
3. 服务器仓库复制路径应为 `spooky-test:/完整路径`。主菜单、工具栏的 Finder 项和右键的 Finder 动作均不可用；本机对应入口仍可用。
4. 服务器终端命令使用所选程序执行 `ssh -t <别名>` 并进入远端路径。测试专用密钥禁止 PTY，不能用它完成交互终端验收；该项需要另行授权的 PTY 测试条件，当前不能据非交互集成测试宣称通过。
5. iTerm、Warp、Ghostty、WezTerm 和 Prompt 在安装后分别验证目录与命令启动。Warp 使用官方 Launch Configuration URI；退出 Spooky 后只清理其自身的临时配置。

Prompt 的 `.command` 接入保留 `#warning`，须在安装 Prompt 3 与 Local Terminal 后实测，不能视作已确认行为。

## 主题、语言和入口审计

1. 分别切换系统浅色与深色外观，截图核对内容底、列表头、边框、文件状态徽标及连接横幅。数值以 `Sources/Spooky/Resources/NamedColors.json` 为准。
2. Themes 列表仅包含 `Default` 和 `Default (Dark)`；分别选中预览，字体框显示 “Menlo Regular – 11.0”；核对正文、背景、选区、增删透明度。浅色新增 / 删除为 18%，深色新增为 18%、删除为 20%。
3. 系统外观切换后默认对应主题随之变化。主题编辑、导入 / 导出和额外主题由 M6 交付，M2 不显示这些入口。
4. 按 M1 语言步骤切换全部支持语言，检查服务器表单、连接状态、错误修复方向、Settings、终端错误和权限说明，没有资源键泄漏。
5. 核对以下入口与快捷键；本里程碑新增动作没有 ⌥ 变体，不绑定其它里程碑的快捷键。

| 动作 | 入口 | 快捷键 / 限制 |
| --- | --- | --- |
| 打开本机仓库 | 管理页、“+”、File | ⌘O |
| 添加服务器仓库 | 管理页、“+”、File | 无快捷键；空输入与非绝对路径禁用主按钮 |
| 刷新 | 工具栏、View | ⌘R；读取时保留旧快照 |
| 仓库管理 | 工具栏、View | ⌃⌘R |
| Settings | App 菜单 | ⌘, |
| 在终端中打开 | File、自定义工具栏、Working Copy / 书签右键 | 无快捷键；没有仓库或书签时禁用 |
| 在 Finder 中显示 | File、自定义工具栏、Working Copy / 书签右键 | 服务器仓库禁用 |
| 复制路径 | Working Copy / 书签右键 | 服务器路径含主机前缀 |
| 工作区 / 历史 | 侧边栏、View | ⌘1 / ⌘2；历史保留 M1 占位 |

源码入口审计应确认没有加入需求外功能，也没有提前加入其它里程碑尚不可用的菜单项。

## 实现说明

- 支持服务器仓库、主机前缀、SSH 主连接、断线保留快照和回调弹窗。
- 状态使用 porcelain v2 与 NUL 分隔，保留动态哈希长度。
- 终端候选包含 Otty，Prompt 使用其自身的 Bundle Identifier。
